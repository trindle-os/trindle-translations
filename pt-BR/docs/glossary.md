As palavras estão em ordem alfabética. O anel tem partes com nomes próprios. Este diagrama mostra onde cada uma fica.

![Uma imagem desenhada do anel com quatro partes numeradas: o meio, os favoritos, as janelas abertas e a bandeja.](img/ring-layout.svg "O que você vai ver: o anel com suas partes numeradas. Foi desenhado para explicar, não é uma captura de tela.")

**Administrador.** Uma pessoa que pode mudar o computador inteiro. As Unidades pedem a senha de um administrador antes de qualquer mudança.

**AppImage.** Um programa guardado em um só arquivo. Você adiciona um em Aplicativos com Adicionar um AppImage, e ele fica em uma pasta própria.

**Aplicativos.** O lugar do Trindle para encontrar, instalar, atualizar e remover programas.

- [Leia sobre os Aplicativos](apps.html)

**Área de transferência.** Onde o computador guarda a última coisa que você copiou, pronta para colar.

**Arquivo `.deb`.** Um programa no formato de pacote do Debian. O Debian é o sistema em que o Trindle é baseado. Um `.deb` que você abre no Trindle vai para a sua própria caixa fechada, em vez de espalhar arquivos pelo sistema.

**Bandeja.** Os pequenos ícones que alguns programas mostram. No Trindle ficam em um arco na parte de baixo do anel.

**Biblioteca.** Um pedaço de código compartilhado de que um programa precisa para rodar. Um aplicativo em caixa traz a sua.

![Uma imagem desenhada de uma pasta para um aplicativo, com o aplicativo, suas bibliotecas e suas configurações, ao lado das suas pastas, ligadas por uma linha pontilhada que significa uma permissão.](img/app-folder.svg "O que você vai ver: um aplicativo em caixa. Foi desenhado para explicar, não é uma captura de tela.")

**Aplicativo em caixa.** Um programa que vive em uma pasta própria, com tudo de que precisa. Ele só pode o que você deixar. Removê-lo remove tudo dele.

**Btrfs.** Um tipo de organização de disco que consegue tirar instantâneos. O disco do próprio Trindle o usa.

**Criptografia.** Embaralhar um disco para que ninguém o leia sem a chave. A chave pode ser uma senha que você digita, ou o chip TPM.

![As perguntas do instalador em ordem: idioma, o disco, criptografia, você, e uma última página chamada Pronto.](img/installer-questions.svg "O que você vai ver: onde se escolhe a criptografia, a terceira pergunta do instalador. Foi desenhado para explicar, não é uma captura de tela.")

**Dual boot.** Dois sistemas em um só disco, com um menu ao ligar para escolher entre eles.

**Favoritos.** Os aplicativos que você deixa por perto no anel. Clique com o botão direito em um aplicativo no anel para adicionar.

**Firmware.** O pequeno programa que roda quando você liga o computador, antes de o sistema iniciar. O Secure Boot é configurado nele.

**Flatpak e Flathub.** O Flatpak é uma forma de empacotar aplicativos para que cada um rode separado dos outros. O Flathub é a loja online deles que os Aplicativos leem.

**Flow.** Um plugin que dá a dois computadores Trindle um só mouse e teclado.

- [Leia sobre o Flow](flow.html)

**Formatar.** Apagar uma parte de uma unidade e prepará-la de novo, para que possa guardar arquivos.

**Home.** Sua pasta pessoal, onde ficam Documentos, Downloads, Imagens e o resto.

**Imagem.** Uma cópia de um sistema inteiro em um só arquivo, que você grava em um pendrive. A imagem do Trindle termina em `.iso`.

**Instantâneo.** Uma cópia salva do sistema como ele estava em um momento, para poder ser restaurado.

**Log.** Um diário que o computador mantém do que os programas fizeram.

**Markdown.** Um jeito de escrever texto simples com marcas simples para títulos e listas. O Texto o entende.

- [Leia sobre o Texto](text.html)

**Máquina virtual.** Um computador de mentira que roda dentro de um de verdade. É uma forma segura de experimentar o Trindle primeiro.

**Menu de inicialização.** Uma lista que o computador mostra ao ligar, para você escolher por onde iniciar. Pressionar uma tecla ao ligar a abre.

**Montar.** Fazer os arquivos de uma unidade aparecerem como uma pasta que você pode abrir.

**NAS.** Um pequeno computador na sua rede que guarda arquivos para outros computadores usarem.

![Um painel ou dois: uma única lista de arquivos, ou duas listas lado a lado com uma faixa entre elas.](img/two-panes.svg "O que você vai ver: um painel e dois painéis nas Pastas. Foi desenhado para explicar, não é uma captura de tela.")

**Painel.** Uma lista de arquivos nas Pastas. As Pastas podem mostrar um painel ou dois.

![Um disco desenhado como uma barra de três partes: outro sistema que fica, o Trindle e espaço livre.](img/disk-parts.svg "O que você vai ver: partições em um disco, como exemplo. Foi desenhado para explicar, não é uma captura de tela.")

**Partição.** Uma parte nomeada de um disco. Um disco pode ter várias.

**Permissão.** Algo que um aplicativo pede para poder fazer, como acessar suas pastas ou o seu microfone. Cada uma tem seu próprio interruptor, desligado até você escolher.

**PIN.** Um número de quatro dígitos que pode desbloquear a tela, assim como a sua senha.

![O caminho de volta na tela de bloqueio: a tela bloqueia, pede uma senha ou PIN, ou um toque no seu celular, e abre.](img/lock-flow.svg "O que você vai ver: como um PIN ou o Pocketkey deixa você voltar a entrar. Foi desenhado para explicar, não é uma captura de tela.")

**Plugin.** Um pequeno extra dos Aplicativos que acrescenta algo ao Trindle. Cada um vive em uma pasta própria e não pode nada até você dizer.

- [Leia sobre os Aplicativos](apps.html)

**Pocketkey.** Um extra incluído que deixa seu celular responder a caixas de senha com um toque. Ele bloqueia a tela quando o celular sai do alcance.

**Porta.** Uma porta numerada que um computador usa para falar com outro por uma rede.

**Anel.** Toda a interface da área de trabalho do Trindle, um círculo que abre e fecha.

- [Leia sobre o anel](ring.html)

**Secure Boot.** Uma opção do firmware que só deixa iniciar software aprovado. Talvez seja preciso desligá-lo para iniciar pelo pendrive.

**Tecla Super.** A tecla muitas vezes marcada com o logotipo do Windows. Ela abre o anel.

**Tema.** Um arquivo que muda todo o visual do Trindle. As Configurações, em Aparência, guardam os temas.

**Todos os aplicativos.** O botão na parte de baixo do anel que mostra tudo o que está instalado. Digitar qualquer letra faz o mesmo.

**TPM.** Um chip no computador que pode desbloquear um disco criptografado sozinho, para que nada seja digitado ao ligar.
