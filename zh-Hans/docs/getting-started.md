Trindle 是一个完整的操作系统，不是装在现有系统里的程序。它会取代电脑上原有的系统，或者与原有系统并存。

> 开始之前，请先备份所有重要的东西。Trindle 会改变电脑的启动、登录和磁盘管理方式。使用风险由你自己承担。

## 你需要准备什么

- 一台搭载 64 位 Intel 或 AMD 处理器的电脑。
- 至少 20 GB 的可用磁盘空间。可以是整块磁盘，也可以是在其他系统旁边腾出的空间。
- 一个 4 GB 或更大的 U 盘。U 盘上的所有内容都会被替换。
- 大约一小时。通常会更快，但请不要在需要用电脑的十分钟前才开始。

## 从下载到桌面的五个步骤

在最后一步之前，电脑上的任何东西都不会改变。

![五个步骤的列表：下载镜像，写入 U 盘，从 U 盘启动，试用 Trindle，点击安装 Trindle。](img/install-steps.svg "你会看到：按顺序排列的五个步骤。这是示意图，不是屏幕截图。")

1. 下载镜像。它是一个 `.iso` 文件，约 1 GB。镜像就是把整个系统复制成一个文件。
2. 用 Impression、balenaEtcher 或 `dd` 把它写入 U 盘。如果用 `dd`，请先确认 U 盘对应的是哪个设备。选错设备会清空错误的磁盘。
3. 从 U 盘启动电脑。插入 U 盘，开机并按住启动菜单键。大多数联想和戴尔电脑是 F12，惠普是 F9，其他品牌是 Escape 或 F11。
4. 试用 Trindle。它直接从 U 盘运行，圆环、应用和设置都能正常使用。它不会向电脑自己的磁盘写入任何东西。
5. 打开圆环，点击“安装 Trindle”。在安装程序的最后一页点击“安装”之前，它不会改变任何东西。

如果开启了安全启动（Secure Boot），你可能需要先把它关掉。安全启动是一项固件设置，只允许经过认可的软件启动。固件是开机时、系统启动之前运行的小程序。

想先在虚拟机里试试？请给它足够的内存，并打开 3D 图形。内存太少会卡得很慢，那样你评判的就是虚拟机，而不是 Trindle。

## 安装程序会问什么

安装程序会问四个问题，然后用几句话给出摘要。每一步都有一个标记沿着一条线移动，让你随时知道进行到哪里。可以一直返回上一步，在你点击“安装”之前不会写入任何东西。

![安装程序按顺序提出的问题：语言、磁盘、加密、你，最后一页叫“准备就绪”。](img/installer-questions.svg "你会看到：安装程序各页的顺序。这是为了说明而画的，不是屏幕截图。")

- **语言。** 只需选一次。键盘和时间会跟着它设置。这里有一个输入框，你可以在把键盘用于输入密码之前先试一试。
- **磁盘。** 可以使用整块磁盘并替换其中的所有内容，也可以保留现有内容并共用这块磁盘。用滑块决定两边各分到多少空间。每块磁盘都以其中的内容命名，方便你选对。
- **加密。** 加密会把磁盘内容打乱，没有密钥就没人能读取。你可以在其他内容出现之前先输入一个密码，也可以让电脑的 TPM 芯片自动解锁。安装程序会告诉你这台电脑能做到哪一种。你也可以不加密磁盘。
- **你。** 你的姓名、登录用的名称、电脑的名称，以及两次输入的密码。

最后一页“准备就绪”会把整个方案用句子复述一遍。此时还没有任何改变。

![一块磁盘画成由三部分组成的长条：保留的另一个系统、Trindle 和可用空间。](img/disk-parts.svg "你会看到：两个系统共用一块磁盘的示例。这是为了说明而画的，不是屏幕截图。")

### 与另一个系统共用磁盘

如果存在有空余空间的 Windows 或 Linux 分区，安装程序会提供保留它并共用磁盘的选项。分区是磁盘上一个有名字的部分。安装程序会把它缩小，再把 Trindle 装进腾出的空间。之后两个系统都会出现在启动菜单中。

调整大小之前，请先备份另一个系统。让 Windows 正常关机，而不是休眠。否则它的分区无法缩小。

## 最初的十分钟

在已安装的电脑上首次登录时，“欢迎”会先于圆环打开。它先问你了解多少，再显示适合你的页面，配有动画图片，文字很少。如果你以前用过 Linux，它会略去所有 Linux 桌面都有的内容。如果你以前用过 Trindle，它会直接关闭，不再出现。

![“欢迎”的第一页：一幅屏幕图片，圆环在中间，旁边有一张列出圆环内容的卡片。](img/welcome.png "你会看到：“欢迎”的第一页。它只打开一次。想再看时，可在“所有应用”里找到“欢迎”。")

Trindle 刚装好时几乎是空的。你可以在“欢迎”里挑选想要的应用，例如浏览器、电子邮件和办公软件。一次点击就能全部安装，你可以边读边等。在你选择之前，没有浏览器。

然后做这三件事。

1. **连接 Wi-Fi。** 打开圆环，点击中间的网络图标，打开 Wi-Fi，找到你的网络，点击“连接”。
2. **设置屏幕大小。** 打开“设置”，再点“显示器”。如果改动后看起来不对，什么都不用做。十五秒后它会自动恢复。
3. **打开锁定。** 打开“设置”，再点“电源”。锁定一开始是关闭的。打开后，用你的密码就能解锁屏幕。如果你设置了四位数 PIN，它也可以解锁。

![圆环的 Wi-Fi 页面：顶部有 Wi-Fi 开关，下面是一列虚构的网络。](img/ring-wifi.png "你会看到：圆环的 Wi-Fi 页面，网络名称都是虚构的。")

![圆环在深色屏幕上打开：中间是时间，周围是小圆按钮，外圈有一个应用。](img/ring.png "你会看到：打开的圆环。几乎所有操作都从这里开始。")

电脑里也有帮助。“设置”里有一个“帮助”页面，断网也能用。“设置”中每个页面的名称旁边都有一个小小的 i，点击它会打开“帮助”中与该页面相关的部分。
