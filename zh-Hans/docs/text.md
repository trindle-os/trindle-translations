“文本”可以打开、编辑和保存纯文本。纯文本、Markdown、日志和源代码文件默认都用它打开。

## 基本功能

- **同时打开多个文件。** 它们会以一排窄窄的标签页打开，每个标签页都有自己的小关闭按钮。文字占据大部分空间。
- **工作不会丢失。** “文本”会随时保存。关闭尚未保存为文件的内容之前，会先询问。
- **保存不会丢掉旧内容。** “文本”会先把新内容写入文档旁边的一个新文件，再一步换掉旧文件。这样，即使中途断电，文件名指向的始终是完整的旧文件或完整的新文件。如果保存中断，“文本”下次启动时会把它修好。
- **其他编码。** 编码是文件里存放字符的方式。除了 UTF-8，“文本”还会按文件原有的编码读取和写入文件。
- **最近的文件。** “文本”会保留一份列表。有一个设置可以决定启动时怎么做：要么重新打开上次的文件，要么从一个空白文档开始。

## 编辑

“文本”有行号、自动换行（可开可关）、查找和替换、词数和字母数统计，以及转到行。

“撤销”和“重做”是顶部栏里保存按钮后面的圆形按钮。没有可撤销或可重做的内容时，它们会变灰。

查找一个词：

1. 按 Ctrl+H，或点按顶部栏里的查找和替换按钮。
2. 在打开的栏里输入这个词。
3. “文本”会在页面里标出找到的词，并统计数量，例如“第 1 个，共 2 个”，用箭头可以在它们之间移动。

![“文本”里打开着一份简短的购物清单，“milk”一词在两处被找到。](img/text-found.png "你会看到：查找栏里输入了“milk”，清单中显示找到的词。")

拼写检查使用电脑上已有的词典。除非“设置”里指定了词典，否则如果有英式英语词典就用它。其次用电脑自己的语言，再其次用美式英语。

你可以更改字体及其大小。外观跟随 Trindle 自己的深色或浅色。

## Markdown

Markdown 是一种书写纯文本的方式，用简单的符号表示标题和列表。在 Markdown 模式下，同一个窗格可以在原始文本和成品效果之间切换，两者不会并排显示。你可以把成品效果保存为 PDF 或 HTML。

## 关闭

- 标题栏的关闭按钮和 Ctrl+Q 会关闭“文本”。每个还有未保存内容的文档，都会依次询问。
- Ctrl+W，或某个标签页自己的关闭按钮，只关闭那一个文档，绝不会关闭“文本”本身。关闭最后一个文档时，会留下一个空白文档。
