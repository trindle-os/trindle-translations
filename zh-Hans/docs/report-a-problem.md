如果出了问题，你可以在一个小窗口里把它写下来，并发送给 Buildmorphic，也就是帮助构建 Trindle 的社区。在你点按“发送”之前，不会发送任何内容。

## 打开它

报告默认是关闭的，要你选择后才会开启。在“设置”的“崩溃报告”里打开“询问问题并分享报告”，或者在首次运行的导览里回答“是，问我”。关闭时，圆环里的“报告问题”按钮不会显示，崩溃后不会询问你，也不会发送任何内容。

## 如何做报告

1. 打开圆环，点按它下面一排里的“报告问题”按钮。
2. 在“您当时在做什么？”的输入框里写下你当时在做什么。
3. 点按“显示详情”，逐字查看整份报告。
4. 点按“发送”。或者点按“取消”关闭窗口，不发送任何内容。

再次点按圆环上的按钮，只会把第一个窗口带到前面，不会再打开一个。

“显示详情”里面还有“保存”和“复制”：“保存”会把报告写入你的“下载”文件夹，“复制”会把同样的文字放到剪贴板上。

## 报告里有什么

窗口里的那行字说明会发送什么：你的电脑型号、显卡和错误信息，绝不会发送你的文件、密码或 Wi-Fi 名称。在你点按“发送”之前，“显示详情”会显示全部内容。

- 你自己写的话。
- Trindle 自己日志的最后 200 行。日志是电脑记下的日记，记录程序做过什么。
- Trindle 的版本。
- 电脑：它的型号、显卡、处理器和内存。
- 崩溃之后，是哪个程序停止了，停在哪里。
- 你的 Buildmorphic 用户名或 GitHub 名称，只有在你于“崩溃报告”页填写了它们时才会包含。

没有别的了。

## 哪些内容会被抹掉

在文字显示、保存或发送之前，Trindle 会抹掉所有能说出你是谁的内容。

- 你自己的主文件夹会变成 `~`。
- 其他任何主文件夹会变成 `/home/[name]`。
- 你的登录名、你全名中的各个字词和电脑的名称会变成 `[name]`。
- Wi-Fi 名称、网络地址和硬件地址会被抹掉。
- 每个电子邮件地址都会变成 `[email]`。

你自己写的话也一样处理。

## 报告去哪里

“发送”会把报告发到 Buildmorphic。窗口会先询问目前是否接收报告，只有接收时才会显示“发送”。询问期间，它会显示“正在检查。”；不接收时，在“发送”的位置会显示“目前暂不接收报告。”

没有网络连接时，你发送的报告会留在这台电脑上等待，连接恢复后自动发出。窗口会显示“正在等待网络连接。”

## 出错时窗口会说什么

文字会出现在你正在操作的位置。

- 字数太少无法发送时，会出现“请再多写几句，说明发生了什么。”
- 无法读取 Trindle 的日志时，会出现“没有可随报告发送的日志，所以无法发送。请改为保存。”
- 发送或保存过一次之后，会出现“已发送。”和“已保存。”
- 文件无法写入时，会出现“无法保存”，后面跟着几个字说明原因。

## 程序崩溃时

当 Trindle 自己的某个程序崩溃时，你会收到一条通知。如果已开启报告，会弹出一个窗口问“出了点问题。要发送报告吗？”，有“发送”和“不发送”两个按钮。每次崩溃只询问一次。

应用的崩溃信息只保存在这台电脑上，绝不会发送出去。
