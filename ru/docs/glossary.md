Слова идут по алфавиту. У частей кольца есть собственные названия. Эта схема показывает, где находится каждая.

![Рисунок кольца с четырьмя пронумерованными частями: середина, избранное, открытые окна и трей.](img/ring-layout.svg "Что вы увидите: кольцо с пронумерованными частями. Это схема для пояснения, а не снимок экрана.")

**Администратор.** Человек, которому разрешено изменять весь компьютер. «Диски» запрашивают пароль администратора перед любым изменением.

**Все приложения.** Кнопка внизу кольца, показывающая всё установленное. То же самое делает набор любой буквы.

**AppImage.** Программа, хранящаяся в одном файле. Вы добавляете её в «Приложениях» через «Добавить AppImage», и она живёт в собственной папке.

**Приложения.** Место в Trindle, где можно находить, устанавливать, обновлять и удалять программы.

- [Прочитать о «Приложениях»](apps.html)

**Меню загрузки.** Список, который компьютер показывает при запуске, чтобы вы могли выбрать, что запускать. Нажатие клавиши при включении открывает его.

![Рисунок папки одного приложения, в которой лежат приложение, его библиотеки и настройки, рядом с вашими папками, соединёнными пунктирной линией, означающей разрешение.](img/app-folder.svg "Что вы увидите: приложение в ящике. Это схема для пояснения, а не снимок экрана.")

**Приложение в ящике.** Программа, которая живёт в собственной папке со всем необходимым. Ей разрешено только то, что вы позволите. Если её удалить, исчезает всё.

**Btrfs.** Вид разметки диска, позволяющий делать снимки. Собственный диск Trindle использует её.

**Буфер обмена.** Место, где компьютер хранит последнее скопированное, готовое к вставке.

**Файл `.deb`.** Программа в формате пакетов Debian. Debian это система, на которой построен Trindle. Файл `.deb`, открытый в Trindle, попадает в собственный закрытый ящик, а не раскидывает файлы по системе.

**Две системы на одном компьютере.** Две системы на одном диске, с меню при запуске для выбора между ними.

![Вопросы установщика по порядку: язык, диск, шифрование, вы и последняя страница «Готово».](img/installer-questions.svg "Что вы увидите: где выбирается шифрование, третий вопрос установщика. Это схема для пояснения, а не снимок экрана.")

**Шифрование.** Перемешивание данных на диске, чтобы никто не мог прочитать их без ключа. Ключом может быть пароль, который вы вводите, или чип TPM.

**Избранное.** Приложения, которые вы держите под рукой в кольце. Чтобы добавить, щёлкните приложение в кольце правой кнопкой.

**Микропрограмма.** Небольшая программа, которая работает при включении компьютера, до запуска системы. Secure Boot настраивается там.

**Flatpak и Flathub.** Flatpak это способ упаковки приложений, при котором каждое работает отдельно от остальных. Flathub это интернет-магазин таких приложений, который читают «Приложения».

**Flow.** Плагин, дающий двум компьютерам с Trindle одну мышь и клавиатуру.

- [Прочитать о Flow](flow.html)

**Форматировать.** Стереть часть диска и подготовить её заново, чтобы на ней можно было хранить файлы.

**Домашняя папка.** Ваша собственная папка, где лежат «Документы», «Загрузки», «Изображения» и остальное.

**Образ.** Копия всей системы в одном файле, которую записывают на USB-накопитель. Образ Trindle имеет расширение `.iso`.

**Библиотека.** Общий фрагмент кода, который нужен программе для работы. Приложение в ящике приносит свои библиотеки с собой.

**Журнал.** Дневник, который компьютер ведёт о том, что делали его программы.

**Markdown.** Способ записи простого текста с несложными пометками для заголовков и списков. Программа «Текст» его понимает.

- [Прочитать о «Тексте»](text.html)

**Подключить (смонтировать).** Сделать так, чтобы файлы диска появились как папка, которую можно открыть.

**NAS.** Небольшой компьютер в вашей сети, который хранит файлы для других компьютеров.

![Одна панель или две: один список файлов или два списка рядом с полосой между ними.](img/two-panes.svg "Что вы увидите: одну панель и две панели в «Папках». Это схема для пояснения, а не снимок экрана.")

**Панель.** Один список файлов в «Папках». «Папки» могут показывать одну панель или две.

![Один диск в виде полосы из трёх частей: другая система, которую оставили, Trindle и свободное место.](img/disk-parts.svg "Что вы увидите: разделы одного диска, для примера. Это схема для пояснения, а не снимок экрана.")

**Раздел.** Отдельная именованная часть диска. На диске их может быть несколько.

**Разрешение.** То, что приложение просит позволить ему, например доступ к вашим папкам или микрофону. У каждого свой переключатель, выключенный, пока вы не выберете иначе.

**PIN-код.** Четырёхзначное число, которым можно разблокировать экран наравне с паролем.

![Путь через экран блокировки: экран блокируется, запрашивает пароль, PIN-код или касание на телефоне и открывается.](img/lock-flow.svg "Что вы увидите: как PIN-код или Pocketkey возвращают вас. Это схема для пояснения, а не снимок экрана.")

**Плагин.** Небольшое дополнение из «Приложений», расширяющее Trindle. Каждый живёт в собственной папке, и ему ничего не разрешено, пока вы не скажете.

- [Прочитать о «Приложениях»](apps.html)

**Pocketkey.** Встроенное дополнение, позволяющее телефону отвечать на запросы пароля одним касанием. Оно блокирует экран, когда телефон уходит из зоны досягаемости.

**Порт.** Пронумерованная «дверь», через которую один компьютер общается с другим по сети.

**Кольцо.** Весь интерфейс рабочего стола Trindle, круг, который открывается и закрывается.

- [Прочитать о кольце](ring.html)

**Secure Boot.** Параметр микропрограммы, разрешающий запуск только проверенного ПО. Чтобы загрузиться с USB-накопителя, его, возможно, придётся выключить.

**Снимок.** Сохранённая копия системы в какой-то момент, чтобы её можно было вернуть.

**Клавиша Super.** Клавиша, часто отмеченная логотипом Windows. Она открывает кольцо.

**Тема.** Один файл, меняющий весь вид Trindle. Темы находятся в «Настройках», в разделе «Оформление».

**TPM.** Чип в компьютере, способный сам разблокировать зашифрованный диск, чтобы при запуске ничего не вводить.

**Трей.** Маленькие значки, которые показывают некоторые программы. В Trindle они расположены дугой внизу кольца.

**Виртуальная машина.** Воображаемый компьютер, который работает внутри настоящего. Это безопасный способ сначала попробовать Trindle.
