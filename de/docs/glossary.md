Die Wörter stehen in der Reihenfolge von A bis Z. Der Ring hat Teile mit eigenen Namen. Dieses Bild zeigt, wo jeder sitzt.

![Eine gezeichnete Darstellung des Rings mit vier nummerierten Teilen: die Mitte, die Favoriten, die offenen Fenster und die Ablage.](img/ring-layout.svg "Das siehst du: den Ring mit nummerierten Teilen. Es ist zur Erklärung gezeichnet, kein Bildschirmfoto.")

**Abbild.** Die Kopie eines ganzen Systems in einer Datei, die du auf einen USB-Stick schreibst. Das Abbild von Trindle endet auf `.iso`.

**Administrator.** Eine Person, die den ganzen Computer ändern darf. Laufwerke fragt vor jeder Änderung nach dem Passwort eines Administrators.

**Alle Apps.** Die Taste unten im Ring, die alles Installierte zeigt. Das Tippen eines beliebigen Buchstabens tut dasselbe.

**AppImage.** Ein Programm in einer einzigen Datei. Du fügst eines in Apps mit AppImage hinzufügen hinzu, und es liegt in einem eigenen Ordner.

**Apps.** Der Ort von Trindle, um Programme zu finden, zu installieren, zu aktualisieren und zu entfernen.

- [Mehr zu Apps](apps.html)

**Bibliothek.** Ein gemeinsam genutzter Teil Code, den ein Programm zum Laufen braucht. Eine App in der Box bringt ihre eigene mit.

**Btrfs.** Eine Art der Festplattenaufteilung, die Schnappschüsse machen kann. Die Festplatte von Trindle nutzt sie.

**Dateisystem einbinden.** Die Dateien eines Laufwerks als Ordner sichtbar machen, den du öffnen kannst.

**`.deb`-Datei.** Ein Programm im Paketformat von Debian. Debian ist das System, auf dem Trindle aufbaut. Eine `.deb`, die du in Trindle öffnest, kommt in eine eigene abgeschlossene Box, statt Dateien über das System zu verteilen.

**Doppelstart.** Zwei Systeme auf einer Festplatte, mit einem Menü beim Start zur Auswahl.

![Die Fragen des Installationsprogramms der Reihe nach: Sprache, die Festplatte, Verschlüsselung, du und eine letzte Seite namens Bereit.](img/installer-questions.svg "Das siehst du: wo die Verschlüsselung gewählt wird, die dritte Frage des Installationsprogramms. Es ist zur Erklärung gezeichnet, kein Bildschirmfoto.")

**Verschlüsselung.** Eine Festplatte so verschlüsseln, dass sie ohne den Schlüssel niemand lesen kann. Der Schlüssel kann ein Passwort sein, das du eintippst, oder der TPM-Chip.

**Favoriten.** Die Apps, die du im Ring griffbereit hältst. Klicke im Ring mit der rechten Maustaste auf eine App, um eine hinzuzufügen.

**Firmware.** Das kleine Programm, das beim Einschalten des Computers läuft, bevor das System startet. Secure Boot wird dort eingestellt.

**Flatpak und Flathub.** Flatpak ist eine Art, Apps so zu verpacken, dass jede getrennt von den anderen läuft. Flathub ist der Online-Laden dafür, den Apps liest.

**Flow.** Ein Plugin, das zwei Trindle-Computern eine gemeinsame Maus und Tastatur gibt.

- [Mehr zu Flow](flow.html)

**Formatieren.** Einen Teil eines Laufwerks löschen und neu einrichten, damit er Dateien aufnehmen kann.

**Home.** Dein eigener Ordner, in dem Dokumente, Downloads, Bilder und das Übrige liegen.

**Log.** Ein Tagebuch, das der Computer darüber führt, was seine Programme getan haben.

**Markdown.** Eine Art, schlichten Text mit einfachen Zeichen für Überschriften und Listen zu schreiben. Text versteht es.

- [Mehr zu Text](text.html)

**NAS.** Ein kleiner Computer in deinem Netzwerk, der Dateien für andere Computer bereithält.

![Ein Bereich oder zwei: eine einzelne Dateiliste oder zwei Listen nebeneinander mit einem Streifen dazwischen.](img/two-panes.svg "Das siehst du: ein Bereich und zwei Bereiche in Ordner. Es ist zur Erklärung gezeichnet, kein Bildschirmfoto.")

**Bereich.** Eine Dateiliste in Ordner. Ordner kann einen Bereich oder zwei zeigen.

![Eine Festplatte als Balken aus drei Teilen: ein anderes System, das bleibt, Trindle und freier Platz.](img/disk-parts.svg "Das siehst du: Partitionen auf einer Festplatte, als Beispiel. Es ist zur Erklärung gezeichnet, kein Bildschirmfoto.")

**Partition.** Ein benannter Teil einer Festplatte. Eine Festplatte kann mehrere haben.

**Berechtigung.** Etwas, das eine App tun darf, wenn du es erlaubst, zum Beispiel an deine Ordner oder dein Mikrofon zu gelangen. Jede hat einen eigenen Schalter, der aus ist, bis du ihn einschaltest.

**PIN.** Eine vierstellige Zahl, die den Bildschirm genauso entsperren kann wie dein Passwort.

![Der Weg zurück auf den Sperrbildschirm: der Bildschirm sperrt sich, fragt nach Passwort oder PIN oder nach einem Tippen auf deinem Telefon und öffnet sich.](img/lock-flow.svg "Das siehst du: wie dich eine PIN oder Pocketkey wieder hineinlässt. Es ist zur Erklärung gezeichnet, kein Bildschirmfoto.")

**Plugin.** Eine kleine Erweiterung aus Apps, die Trindle etwas hinzufügt. Jedes liegt in einem eigenen Ordner und darf nichts, bis du es sagst.

- [Mehr zu Apps](apps.html)

**Pocketkey.** Eine eingebaute Erweiterung, mit der dein Telefon mit einem Tippen Passwortfelder beantwortet. Sie sperrt den Bildschirm, wenn das Telefon außer Reichweite ist.

**Port.** Eine nummerierte Tür, über die ein Computer in einem Netzwerk mit einem anderen spricht.

**Ring.** Die ganze Oberfläche von Trindle, ein Kreis, der sich öffnet und schließt.

- [Mehr zum Ring](ring.html)

**Secure Boot.** Eine Firmware-Einstellung, die nur freigegebene Software starten lässt. Um vom USB-Stick zu starten, musst du sie vielleicht ausschalten.

**Schnappschuss.** Eine gespeicherte Kopie des Systems, wie es in einem Augenblick war, damit es zurückgespielt werden kann.

**Super-Taste.** Die Taste, die oft ein Windows-Logo trägt. Sie öffnet den Ring.

**Thema.** Eine Datei, die das ganze Aussehen von Trindle ändert. Die Einstellungen halten sie unter Aussehen bereit.

**TPM.** Ein Chip im Computer, der eine verschlüsselte Festplatte von selbst entsperren kann, sodass beim Start nichts eingetippt wird.

**Ablage.** Die kleinen Symbole, die manche Programme zeigen. In Trindle liegen sie in einem Bogen unten im Ring.

**Startmenü.** Eine Liste, die der Computer beim Start zeigt, damit du wählen kannst, wovon er starten soll. Eine Taste beim Einschalten öffnet sie.

![Eine gezeichnete Darstellung eines Ordners für eine App, der die App, ihre Bibliotheken und ihre Einstellungen enthält, neben deinen eigenen Ordnern, verbunden durch eine gepunktete Linie, die eine Berechtigung bedeutet.](img/app-folder.svg "Das siehst du: eine App in der Box. Es ist zur Erklärung gezeichnet, kein Bildschirmfoto.")

**App in der Box.** Ein Programm, das mit allem, was es braucht, in einem eigenen Ordner liegt. Es darf nur, was du erlaubst. Wenn du es entfernst, ist alles davon weg.

**Virtuelle Maschine.** Ein gespielter Computer, der in einem echten läuft. Eine sichere Möglichkeit, Trindle zuerst auszuprobieren.

**Zwischenablage.** Dort hält der Computer das Letzte, was du kopiert hast, bereit zum Einfügen.
