Quand l'écran se verrouille, l'écran de verrouillage demande votre mot de passe, ou un code PIN si vous en avez choisi un. Il ne montre que l'heure, la date et la zone du mot de passe.

L'écran de verrouillage ne peut pas être photographié sans un vrai écran, et une image inventée ne serait pas honnête. Cette page utilise donc un schéma dessiné. Il est présenté comme un schéma. Ce n'est pas une capture d'écran.

## L'activer

Au départ, le verrouillage est désactivé.

1. Ouvrez Réglages et choisissez Alimentation.
2. Dans la carte Verrouillage, activez Verrouiller l'écran.
3. Choisissez le délai avant le verrouillage avec Verrouiller après.

Une fois le verrouillage activé, votre mot de passe vous fait revenir. Un code PIN à quatre chiffres le fait aussi, si vous en choisissez un en plus.

![La page Alimentation dans Réglages avec une image de batterie, le mode d'alimentation, les délais d'assombrissement de l'écran et une carte Verrouillage.](img/settings-power.png "Ce que vous verrez : la page Alimentation de Réglages. La carte Verrouillage sert à activer le verrouillage.")

## Revenir

Tapez votre mot de passe ou votre code PIN.

Chaque zone a un petit œil. Appuyez dessus pour voir ce que vous avez tapé. Vous pouvez aussi appuyer sur Tab pour l'atteindre, puis sur Espace ou Entrée.

Le mot de passe se cache de nouveau après votre essai. Il se cache aussi quand aucune touche n'a été pressée pendant 30 secondes. Il ne reste donc jamais affiché sur un écran que quelqu'un a quitté.

## Ce qui reste caché

Tant que l'écran est verrouillé, aucune notification ne s'affiche. Pas même ses mots ni le nom de l'application. Elles attendent dans les notifications de l'anneau que vous déverrouilliez.

## Pocketkey

Pocketkey est un complément intégré pour votre téléphone. Activez-le dans Apps. L'écran de verrouillage montre alors un bouton de téléphone.

Un téléphone associé, dans votre poche, transforme les demandes de mot de passe en un seul toucher, oui ou non. L'écran se verrouille quand le téléphone est hors de portée. Le mot de passe fonctionne toujours.

- [En savoir plus sur Apps](apps.html)

## Verrouiller depuis Flow

Si vous utilisez Flow, un verrouillage rend aussitôt la souris et le clavier à l'ordinateur auquel ils appartiennent.

- [En savoir plus sur Flow](flow.html)

## L'économiseur d'écran

Alimentation propose aussi un réglage nommé Afficher l'horloge mobile après. Il montre l'heure seule, qui se déplace lentement sur l'écran. Vous choisissez le délai, une fois pour la batterie et une fois pour quand l'ordinateur est branché.
