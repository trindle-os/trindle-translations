Folders adalah tempat Anda menjelajahi, membuka, menyalin, memindahkan, dan merapikan file. Bukalah dari cincin.

## Satu panel atau dua

Panel adalah satu daftar file. Folders dibuka dengan satu panel.

1. Cari sakelar Tunggal dan Ganda di sisi kiri bilah atas.
2. Tekan sakelar itu, atau tekan F3. Perubahannya langsung terjadi.
3. Pilihan Anda diingat untuk lain kali.

![Gambar Folders dengan satu panel, dan dengan dua panel berdampingan dengan sebaris tombol di antaranya.](img/two-panes.svg "Yang akan Anda lihat: diagram satu panel dan dua panel. Ini gambar untuk menjelaskan, bukan tangkapan layar.")

Dengan satu panel, Folders mulai di Beranda. Dengan dua panel, panel kiri mulai di Beranda dan panel kanan di Terbaru. Di pengaturan Folders sendiri, Anda bisa memilih tempat mulai tiap panel, atau meneruskan dari tempat terakhir Anda.

Dengan dua panel, masing-masing adalah kartu tersendiri. Sebaris tombol berada di antara keduanya. Baris tombol itu bisa menampilkan folder ini di panel lain, menukar kedua panel, memilih apa yang berbeda dari panel lain, menautkan kedua panel, dan membandingkannya.

Panel yang sedang Anda pakai punya tepi kartu yang sedikit berbeda. Itu menunjukkan panel mana yang akan berubah saat Anda mengklik bilah samping. Kedua panel selalu sama lebar.

![Folders dengan dua panel berdampingan, masing-masing menampilkan daftar file rekaan, dengan sebaris tombol di antaranya.](img/folders-dual.png "Yang akan Anda lihat: Folders dengan dua panel dan folder rekaan.")

## Bilah samping

Bilah samping punya bagian Disematkan untuk folder yang Anda sematkan. Di bawahnya ada Tempat: Penyimpanan, Terbaru, dan Tempat sampah.

Klik kanan sebuah folder untuk menyematkannya. Jika Anda belum menyematkan apa pun, Unduhan dan Dokumen disematkan untuk Anda. Jika Anda melepas sematan salah satunya, folder itu tidak muncul lagi.

## Melihat file Anda

Ada tiga tampilan: Ikon, Daftar, dan Ringkas. Di Daftar, Anda memilih kolom yang ditampilkan, seperti ukuran, jenis, dan tanggal diubah.

Folders membuat gambar kecil dari gambar, video, dan PDF Anda. Program terpisah membaca video dan PDF di dalam kotak tertutup tanpa jaringan. File berbahaya tidak bisa menjangkau apa pun yang lain.

![Folders dalam tampilan Ikon: empat folder, Dokumen, Unduhan, Musik, dan Gambar, digambar sebagai ikon besar.](img/folders-icons.png "Yang akan Anda lihat: folder yang sama dalam tampilan Ikon. Daftar dan Ringkas adalah dua tampilan lainnya.")

Tekan Space pada video atau lagu dan langsung diputar. Anda mendapat jeda, penggeser, dan volume tanpa membuka aplikasi lain.

## Menu klik kanan

Tingkat pertama menu menampilkan paling banyak dua belas baris. Baris yang paling jarang dipakai ada di empat submenu: Pilih, Kemas, kirim, dan bagikan, Gambar, dan Alat. Tiap baris punya satu tempat, jadi Anda menemukannya di tempat yang sama apa pun yang Anda klik kanan.

![Menu klik kanan pada sebuah folder di Folders, dengan baris seperti Folder baru, Buka, Potong, Salin, Ganti nama, Kemas, kirim, dan bagikan, Alat, Pindahkan ke Tempat sampah, dan Properti.](img/folders-menu.png "Yang akan Anda lihat: menu klik kanan pada sebuah folder. Kemas, kirim, dan bagikan serta Alat membuka submenu.")

Hapus tidak pernah menjadi baris pertama sebuah submenu. Hapus bersih secara aman dan Hapus permanen berada sejauh mungkin dari Buka di dalam menu.

Setiap file bisa dibuka. Jika nama file tidak menunjukkan jenisnya, Folders membaca bagian awalnya. File kosong atau file teks biasa dibuka di Text. Jika tidak ada aplikasi yang membuka suatu jenis, jendela Buka dengan muncul agar Anda memilih satu.

## Komputer lain
Questions: mengapa NAS saya tidak mau terbuka; bagaimana cara menemukan folder bersama di jaringan saya; bagaimana cara melihat komputer lain di Folders

Jaringan menemukan komputer di jaringan Anda yang membagikan folder, seperti NAS. NAS adalah komputer kecil yang menyimpan file untuk seluruh rumah. Folders mencari dengan dua cara sekaligus dan mencantumkan tiap komputer satu kali. Buka salah satunya untuk melihat folder bersamanya.

Jika tidak ada komputer yang ditemukan, Folders mengatakannya, dan menyebutkan apa yang ditanyakannya.

Login yang Anda ketik untuk folder bersama bisa diingat selama 90 hari. Sakelarnya menyebutkan hal itu. Login yang diingat hanya dikirim ke alamat yang pernah dipakai sebelumnya. Jika komputer menjawab di alamat baru, Folders bertanya lagi dan menjelaskan alasannya.

Alamat nfs:// hanya terbuka di server yang menawarkan NFS versi 4. Versi 3 hanya ditemukan di kotak NAS yang sangat tua, dan Trindle tidak memakainya agar tidak ada tambahan yang terus berjalan. Jika server tidak menawarkan versi 4, label di bawah file menyatakannya.

Menyimpan file kembali ke komputer lain menulis salinan baru lebih dulu. Salinan itu baru menggantikan yang lama setelah lengkap, jadi sambungan yang putus tidak pernah meninggalkan file yang separuh.

## Menyalin dan memindahkan

Tempel di Folders hanya memindahkan apa yang Anda potong di Folders. File yang dipotong di program lain disalin, dan aslinya tetap ada.

![Folders dengan kartu di bagian bawah bertuliskan Menyalin 3 item ke Dokumen, sebuah persentase, cincin yang terisi, dan tombol jeda dan berhenti.](img/folders-copy.png "Yang akan Anda lihat: penyalinan yang sedang berjalan. Kartu di bagian bawah punya tombol jeda dan berhenti.")

Selama penyalinan besar berjalan, satu baris tenang di barisnya menyatakan bahwa penyalinan memakai disk dengan berat. Program lain mungkin terasa lebih lambat sampai selesai.

## Pengaturan Folders sendiri

Folders menyimpan pengaturannya di Folders.

1. Tekan roda gigi bundar di ujung bilah atas, atau tekan Ctrl dan koma.
2. Sebuah kartu terbuka di atas jendela.
3. Ubah apa yang Anda mau. Perubahan disimpan sambil jalan. Tidak ada tombol Simpan.

Kartu itu mencakup cara Folders dibuka, akhiran file dan kotak centang, pembukaan drive, dan login yang disimpan Folders.

![Kartu pengaturan Folders di atas daftar berkas. Tab berbunyi Saat Folders dibuka, Daftar, Drive, Login tersimpan dan Berbagi. Tiga pilihan menentukan di mana Folders mulai, dan dua kotak mengatur panel kiri dan kanan.](img/folders-settings.png "Yang akan Anda lihat: kartu pengaturan, dibuka dari roda gigi bulat di bilah atas.")

## Berdiri sendiri

Folders adalah aplikasi tersendiri. Folders tidak memerlukan cincin atau bagian Trindle lainnya untuk berjalan, dan mungkin suatu hari ditawarkan sendiri. Hal yang menjangkau ke luar, seperti menyematkan ke cincin atau membuka Pengaturan, hanya muncul bila bagian itu ada.

## Arsip meminta kata sandi
Questions: mengapa zip saya meminta kata sandi; mengapa Folders bilang kata sandi itu tidak bisa membukanya; bagaimana cara membuka RAR yang terkunci; mengapa saya tidak bisa membuka 7z yang dilindungi kata sandi; apa arti dikunci dengan kata sandi

Beberapa file zip dan 7z dikunci dengan kata sandi. Saat Anda membuka atau mengekstrak salah satunya, Folders memintanya di kartu kecil bernama **Kata sandi untuk** dan nama file itu. Ketik kata sandinya lalu tekan **Buka** atau **Ekstrak**.

![Folders dengan kartu kecil di atas daftar berkas. Kartu berjudul Kata sandi untuk holiday.zip, menyatakan berkas dikunci dengan kata sandi, dan punya kotak kata sandi kosong serta tombol Ekstrak.](img/folders-archive-password-card.png "Yang akan Anda lihat: kartu Kata sandi untuk arsip yang terkunci. Kotaknya kosong.")

Jika kata sandinya bukan yang benar, kartu tetap ada dan mengatakannya dengan kata-kata merah di bawah kotak: "Kata sandi itu tidak bisa membukanya." Ketik yang lain dan coba lagi. Kata sandi hanya disimpan selama arsip terbuka dan tidak pernah disimpan ke disk.

![Kartu Kata sandi untuk holiday.zip yang sama setelah kata sandi salah. Kata-kata merah di bawah kotak menyatakan Kata sandi itu tidak membukanya, dan tombol Selengkapnya bulat ada di bagian bawah kartu.](img/folders-archive-password-wrong.png "Yang akan Anda lihat: kartu setelah kata sandi salah. Kata-kata merah ada di bawah kotak.")

![Kartu Kata sandi untuk holiday.zip setelah kata sandi yang tidak cocok dengan kedua cara. Kata-kata merah di bawah kotak menyatakan kata sandi itu tidak membukanya, atau arsipnya rusak, dengan tombol Selengkapnya bulat.](img/folders-archive-password-or-damaged.png "Yang akan Anda lihat: kartu saat Folders tidak dapat membedakan kata sandi salah dari arsip yang rusak.")

Beberapa pesan berbeda:

- "Dikunci dengan kata sandi dan dikemas dengan cara yang tidak bisa dibuka Folders." Tidak ada pembaca milik Folders yang bisa membuka jenis ini.
- "Ini RAR yang dikunci dengan kata sandi, yang tidak bisa dibuka Folders; tidak ada yang salah dengan filenya." Pakai program yang bisa membuka RAR.
- "Kata sandi itu tidak bisa membukanya, atau arsipnya rusak." Pada beberapa arsip, terutama 7z, Folders tidak bisa membedakan keduanya, jadi menyebut keduanya. Periksa kata sandinya dulu. Jika Anda yakin kata sandinya benar, file mungkin rusak: unduh atau salin lagi.
- "holiday.zip dikunci dengan kata sandi. Buka lagi untuk mengetiknya." Ada jendela lain yang terbuka di atas Folders, jadi kartunya tidak bisa muncul. Tutup jendela itu, lalu buka arsipnya lagi.

:::expert
Kata sandi disimpan di memori hanya selama sebuah panel menampilkan arsip, dan dihapus dari memori saat kartu hilang. Zip dibaca dengan kunci zip tradisional dan dengan AES; 7z dibaca dengan kunci AES miliknya sendiri. 7z yang nama filenya juga dikunci memerlukan kata sandi hanya untuk melihat isinya.
:::

## Arsip tidak mau terbuka
Questions: mengapa Folders tidak mau membuka arsip saya; apa arti bukan arsip yang bisa dibuka Folders; mengapa arsip terpisah tidak terbuka; mengapa bagian Trindle yang membaca jenis ini hilang; apa arti rusak atau terpotong

Folders membuka arsip seperti folder, supaya Anda bisa melihat isinya. Saat tidak bisa, kata-kata merah menyebutkan sebabnya dengan singkat. Inilah sebab-sebabnya.

![Sebuah panel dibuka pada broken.zip. Panel kosong kecuali kata-kata merah yang menyatakan broken.zip tidak dapat dibaca karena rusak atau terpotong, diulang di bagian bawah di samping tombol Selengkapnya bulat.](img/folders-archive-not-opened.png "Yang akan Anda lihat: zip yang tidak dapat dibaca. Kata-kata merah ada di bagian bawah, dengan Selengkapnya di sampingnya.")

- **Ini bukan arsip yang bisa dibuka Folders.** Folders melihat akhiran nama dan byte pertama file. File itu mungkin bukan arsip sama sekali, atau jenis yang tidak dibaca Folders. Pastikan file itu memang yang Anda maksud.
- **Rusak atau terpotong.** File berakhir terlalu cepat atau isinya tidak masuk akal. Ini sering terjadi pada unduhan yang berhenti di tengah jalan. Ambil lagi filenya.
- **Dikemas dengan cara yang tidak bisa dibaca Folders.** Arsip memakai metode yang tidak dikenal Folders.

![Sebuah panel dibuka pada notes.zip. Kata-kata merah menyatakan notes.zip tidak dapat dibaca karena bukan arsip yang dapat dibuka Folders, diulang di bagian bawah di samping tombol Selengkapnya bulat.](img/folders-archive-not-an-archive.png "Yang akan Anda lihat: berkas yang bukan arsip yang dapat dibuka Folders.")

- **Ada bagian yang hilang, dan semua bagian harus ada di folder yang sama.** Arsip terpisah terdiri dari beberapa file. Taruh semuanya di satu folder, lalu buka yang pertama.
- **Bagian Trindle yang membaca jenis ini hilang, dan memasang pembaruan akan mengembalikannya.** Jenis seperti RAR, citra disk, dan file .deb dibaca oleh pembaca yang datang bersama Trindle. Pasang pembaruan yang menunggu, lalu coba lagi.
- **File itu sudah tidak ada.** File dipindahkan atau dihapus setelah Folders menampilkannya.
- **Tidak bisa dibaca.** Folders tidak diberi sebab yang lebih jelas.

![Sebuah panel dibuka pada old.7z. Kata-kata merah menyatakan old.7z tidak dapat dibaca karena 7z yang rusak yang bagiannya berakhir terlalu cepat, diulang di bagian bawah di samping tombol Selengkapnya bulat.](img/folders-archive-damaged-7z.png "Yang akan Anda lihat: 7z yang rusak di dalamnya.")

Jika Folders bisa mengetahui apa yang salah di dalam zip atau 7z, Folders menyebutkannya setelah "zip rusak" atau "7z rusak": misalnya pemeriksaan tidak cocok, sebuah bagian berakhir terlalu cepat, header terlalu besar, atau hitungan terlalu besar. Semua ini berarti file rusak atau dibuat agar tampak salah. Ambil lagi filenya.

Jika Anda sedang mengambil sesuatu dari arsip, kalimatnya dimulai dengan "Tidak bisa diambil dari arsip" dan diakhiri dengan salah satu sebab di atas.

:::expert
Zip, tar (biasa, gzip, bzip2, dan xz), dan 7z dibaca oleh kode Folders sendiri. Jenis lainnya dibaca oleh libarchive milik sistem, yang dikurung di dalam kotak tanpa jaringan dan tanpa akses ke file Anda yang lain. Arsip berbahaya tidak bisa menjangkau apa pun yang lain. Jika kotak atau pembacanya hilang, sebabnya adalah baris "bagian Trindle" di atas.
:::

## Arsip tidak mau diekstrak di sini
Questions: mengapa arsip saya tidak mau diekstrak; apa arti tidak ada cukup ruang di sini untuk isinya; mengapa dikatakan isinya lebih dari sejuta item; mengapa perlu lebih banyak memori atau waktu daripada yang diizinkan Folders; mengapa nama tidak bisa diambil

Mengekstrak dilakukan dengan hati-hati. Folders tidak akan memenuhi drive sampai penuh, dan membatasi apa yang boleh diminta arsip orang asing dari komputer Anda. Inilah sebab Folders berhenti.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan satu item tidak dapat diekstrak, big.7z, karena tidak ada ruang di sini untuk isinya, dengan tombol Selengkapnya bulat di kanan.](img/folders-archive-no-room.png "Yang akan Anda lihat: bagian bawah jendela setelah ekstrak berhenti. Selengkapnya ada di kanan.")

- **Tidak ada cukup ruang di sini untuk isinya.** Drive tujuan ekstrak punya ruang kosong lebih sedikit daripada yang dibutuhkan arsip. Folders selalu menyisakan sedikit, jadi berhenti sedikit sebelum drive penuh. Kosongkan ruang atau ekstrak ke drive lain.
- **Tidak ada yang bisa ditulis di folder itu.** Folder itu hanya-baca, atau Anda tidak berhak menaruh file di dalamnya. Ekstrak ke folder milik Anda sendiri.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan satu item tidak dapat diekstrak, big.7z, karena tidak ada yang dapat ditulis di folder itu, dengan tombol Selengkapnya bulat di kanan.](img/folders-archive-no-write.png "Yang akan Anda lihat: bagian bawah jendela saat folder tidak dapat ditulisi.")

- **Isinya lebih dari sejuta item.** Folders tidak akan mengekstrak lebih dari sejuta item dari satu arsip.
- **Membacanya memerlukan lebih banyak memori atau waktu daripada yang diizinkan Folders.** Beberapa arsip sengaja dibuat sangat berat untuk dibuka. Folders berhenti daripada memperlambat seluruh komputer.
- **7z ini memerlukan lebih banyak memori untuk diekstrak daripada yang mau diberikan Folders.** Aturan yang sama, untuk 7z yang pengaturannya meminta jumlah yang sangat besar.
- **N tidak bisa diambil, karena namanya menjangkau ke luar atau ada sesuatu yang menghalangi.** Arsip bisa berisi nama yang mencoba keluar dari folder Anda. Folders menolak yang itu dan mengekstrak sisanya.

:::expert
Ruang yang disisakan di drive adalah 256 MB. Kotak yang membaca jenis lain boleh memakai memori 2 GB. Mendaftar nama dalam arsip boleh memakai waktu prosesor sampai 120 detik, dan mengekstrak sampai dua jam. 7z dengan kamus lebih besar dari 2 GB ditolak. Tidak ada yang ditulis di luar folder yang Anda pilih, tautan dibuat terakhir dan tidak boleh menunjuk ke luar, dan tidak ada yang keluar dari arsip yang pernah dijalankan.
:::

## Pekerjaan yang tidak selesai
Questions: mengapa file saya tidak bisa disalin; mengapa pemindahan meninggalkan file; apa arti dibiarkan; mengapa penghapusan tidak berhasil; apa arti kata dalam kurung setelah nama file

Saat penyalinan, pemindahan, atau penghapusan tidak selesai, kata-kata merah menyebutkan berapa item yang gagal. Folders menyebut tiga yang pertama, lalu "dan N lagi". Tiap nama mungkin punya sebab dalam kurung di belakangnya. Jika tidak ada kurung, Folders tidak diberi sebab untuk item itu.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan dua item tidak dapat disalin dan menyebut holiday plans.txt dan notes.txt dengan alasan untuk masing-masing, dengan tombol Selengkapnya bulat di kanan.](img/folders-work-failed.png "Yang akan Anda lihat: bagian bawah jendela setelah penyalinan yang dua itemnya gagal.")

Arti sebab-sebabnya:

- **Tidak ada saat diperiksa, jadi dibiarkan.** Item tersembunyi atau tautan sudah hilang saat Folders sampai di sana.
- **Terlalu besar untuk diperiksa penuh, jadi dibiarkan.** Item tersembunyi atau tautan berada di folder yang terlalu besar untuk ditelusuri sampai akhir.
- **Berubah sejak dijatuhkan, jadi tidak ada yang dibawa.** Anda menyeretnya dari program lain dan isinya berubah sebelum Folders mengambilnya.
- **Sementara itu ada yang lain diberi nama itu.** Program lain membuat file dengan nama itu setelah Folders melihat folder.
- **Yang sudah ada tidak bisa masuk ke Tempat sampah.** Anda memilih untuk menggantikan sesuatu. Folders tidak bisa memasukkan yang lama ke Tempat sampah lebih dulu, jadi keduanya dibiarkan.
- **Berubah setelah disalin, jadi masih di tempat semula.** Dalam pemindahan, Folders menyalin lebih dulu. Aslinya dihapus hanya bila salinan terbukti utuh. Yang ini berubah, jadi aslinya tetap ada.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan drive HOLIDAY tidak mau menyatakan telah menyimpan yang ditulis, dan report.pdf tidak dapat disalin, dengan tombol Selengkapnya bulat di kanan.](img/folders-work-not-kept.png "Yang akan Anda lihat: drive yang tidak mau menyatakan telah menyimpan yang ditulis.")

- **Drive tidak menyimpan apa yang ditulis, jadi sebagian mungkin tidak ada.** Drive tidak memastikan bahwa semuanya sampai. Periksa salinannya sebelum Anda mengandalkannya.
- **Tidak semuanya bisa dibaca.** Daftar sebuah folder berhenti di tengah jalan.
- **Berada di dalam yang akan digantikannya.** Anda tidak bisa mengganti folder dengan sesuatu yang ada di dalamnya.
- **Salinan ini yang membuatnya.** Sebuah folder disalin ke dalam dirinya sendiri, jadi Folders tidak menyalin folder baru yang baru saja dibuat oleh penyalinan itu.
- **Salinan tidak sama dengan yang dibaca.** Yang ditulis tidak cocok dengan yang dibaca, jadi Folders menolaknya.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan satu item tidak dapat disalin, Letters, karena tidak semuanya dapat dibaca, dengan tombol Selengkapnya bulat di kanan.](img/folders-work-not-all.png "Yang akan Anda lihat: folder yang daftarnya berhenti di tengah jalan.")

Sebab lain yang mungkin Anda lihat:

- **Tidak bisa ditelusuri sampai akhir, jadi masih di tempat semula.** Folder terlalu besar atau terlalu lambat untuk diperiksa sebelum dipindahkan.
- **Tidak bisa disingkirkan.** Salinan sudah utuh, tetapi aslinya tidak bisa dihapus, jadi keduanya ada.
- **Tidak bisa masuk ke Tempat sampah.** Drive ini tidak punya tempat aman untuk Tempat sampah, tidak ada yang dipindahkan, atau Tempat sampah sudah berisi terlalu banyak item dengan nama itu. Hapus permanen, jika memang itu maksud Anda, atau kosongkan ruang.
- **Tidak dipindahkan, dengan jumlah file yang tidak terbaca, file sistem, atau hal lain yang tertinggal.** Folder hanya disingkirkan bila semua isinya terbukti sudah sampai, jadi folder yang berisi hal-hal seperti itu tetap di tempatnya.
- **Hanya gambar JPEG, PNG, WebP, dan BMP yang bisa diputar, gambar tidak bisa dibaca, atau bukan jenis gambar yang ditulis Folders.** Ini untuk Putar dan Ubah ukuran.
- **Penggantian nama berhenti di tengah jalan.** Penggantian nama massal menemui hal yang tidak bisa dilakukannya lalu berhenti. Sebabnya menyusul.

Folders menyingkirkan aslinya hanya setelah salinannya terbukti utuh, jadi item yang disebut di sini masih di tempat semula. Coba lagi dengan item lebih sedikit, atau satu per satu.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan satu item tidak dapat dimasukkan ke Tempat Sampah, budget.ods, karena tidak dapat masuk ke Tempat Sampah, dengan tombol Selengkapnya bulat di kanan.](img/folders-work-no-trash.png "Yang akan Anda lihat: bagian bawah jendela saat sesuatu tidak dapat masuk ke Tempat Sampah.")

:::expert
Pemindahan antar drive menyalin, membuktikan tiap salinan utuh, dan baru lalu menghapus aslinya, jadi pemindahan yang gagal meninggalkan aslinya di tempat. File dihitung sudah dipindahkan hanya setelah salinannya diketahui lengkap.
:::

## Pilihan yang tidak tersimpan
Questions: mengapa Folders melupakan tampilan saya; mengapa kolom saya kembali seperti semula; apa arti tidak dapat disimpan untuk lain kali; mengapa Folders tidak bisa menyimpan pengaturan saya

Folders menyimpan pilihan Anda di file kecil miliknya sendiri di folder `trindle` pada pengaturan Anda, seperti `folders.conf` dan `files-views`. Isinya mencakup panel, tampilan, pengelompokan, kolom, dan ukuran ikon. Saat Folders mengatakan sebuah pilihan "tidak dapat disimpan untuk lain kali" atau "tidak dapat disimpan", pilihan itu berlaku sampai Anda menutup Folders, lalu kembali seperti semula.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan Kolom tidak dapat disimpan, dengan tombol Selengkapnya bulat di kanan.](img/folders-choice-not-kept.png "Yang akan Anda lihat: bagian bawah jendela saat sebuah pilihan tidak dapat disimpan.")

File tidak bisa ditulis bila disk penuh atau folder tidak bisa ditulisi. Ada satu sebab lagi. Jika file pengaturan ada tetapi tidak bisa dibaca, Folders membiarkannya apa adanya dan tidak menulis apa pun, jadi tidak ada isinya yang hilang.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan pilihan satu panel atau dua tidak dapat disimpan, dengan tombol Selengkapnya bulat di kanan.](img/folders-choice-panes-not-kept.png "Yang akan Anda lihat: pilihan lain yang tidak dapat disimpan.")

Favorit cincin dan folder yang disematkan disimpan dengan cara yang sama, dan mengatakannya dengan kata-kata yang sama bila tidak bisa disimpan. Dua baris lagi termasuk di sini: bagian tengah cincin memuat 12 favorit dan mengatakan penuh sampai Anda melepas satu, dan nama yang hurufnya tidak bisa ditampung daftar tidak bisa disimpan di cincin.

Yang harus dilakukan: kosongkan ruang di disk, atau periksa bahwa folder pengaturan boleh Anda tulisi. Jika file tidak bisa dibaca, [laporkan masalah](report-a-problem.html).

Hal yang sama berlaku untuk baris di jendela pengaturan Folders sendiri, seperti "Tidak dapat disimpan." Kata-kata sesudahnya menyebutkan sebabnya. Jika file pengaturan ada tetapi tidak bisa dibaca, jendela menampilkan jawaban biasa dan mengatakan tidak ada yang bisa diubah sampai file bisa dibaca.

:::expert
Folders membaca dan menulis ini sendiri, jadi berjalan sendiri tanpa file pengaturan Trindle. `folders.conf` berisi satu baris untuk tiap pengaturan sebagai `name=value`; file untuk warna, emblem, dan tampilan berisi satu baris untuk tiap folder. Masing-masing ditulis sebagai file baru yang menggantikan yang lama sekaligus utuh. Favorit cincin disimpan di file milik cincin sendiri. Nama yang tidak bisa disimpan di file pengaturan, atau nilai yang berisi pemisah baris, ditolak sebelum apa pun disentuh.
:::

## Program tidak mau dijalankan
Questions: mengapa Folders tidak membuka file saya di aplikasi yang saya pilih; mengapa jendela baru tidak terbuka; mengapa tidak ada program email untuk berbagi; mengapa gambar latar tidak bisa diatur; mengapa Folders tidak bisa dibuka sebagai administrator

Beberapa baris di Folders menyerahkan file Anda ke program lain. Saat program itu tidak bisa dijalankan, kata-kata merah menyebut namanya, atau menyatakan apa yang Anda coba lakukan.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan Folders tidak dapat dibuka sebagai administrator, dengan tombol Selengkapnya bulat di kanan.](img/folders-program-not-started.png "Yang akan Anda lihat: bagian bawah jendela saat sebuah program tidak mau mulai.")

- **Aplikasi tidak bisa dijalankan.** Aplikasi yang Anda pilih di Buka dengan sudah tidak ada, atau tidak mau jalan. Pilih yang lain, atau pasang lagi dari Aplikasi.
- **Tidak ada program email untuk berbagi.** Bagikan lewat email memerlukan program email. Pasang satu dari Aplikasi. Baris ini juga mengatakannya bila yang Anda pilih hanya folder, karena folder tidak bisa dilampirkan.
- **Jendela baru tidak bisa dibuka.** Folders menjalankan salinan keduanya untuk ini, dan itu gagal.
- **Folders tidak bisa dibuka sebagai administrator.** Jendela administrator tidak mulai.
- **Gambar latar tidak bisa diatur.** Program gambar latar Trindle tidak berjalan.

Jika baris yang sama gagal setiap kali, [laporkan masalah](report-a-problem.html) dan sebutkan apa yang Anda tekan.

:::expert
Bagikan lewat email meminta `xdg-email` melampirkan file, yang menyerahkannya ke program email Anda. Jendela baru adalah program Folders yang sama dijalankan lagi pada folder yang dipilih.
:::

## Ada bagian yang tidak ada di komputer ini
Questions: mengapa Folders bilang ada bagian yang tidak ada di komputer ini; mengapa saya tidak bisa membagikan folder; mengapa saya tidak bisa membuka folder bersama Windows; mengapa tidak ada terminal untuk membuka folder ini; mengapa saya tidak bisa berbagi dengan program AI

Folders dibuat agar bisa berjalan sendiri, tanpa bagian Trindle lainnya. Beberapa baris memerlukan bagian yang bukan bagian dari Folders, dan di komputer yang tidak memilikinya, Folders mengatakannya, bukan diam saja.

- **Membagikan folder** diatur oleh pembantu milik Trindle.
- **Membuka folder bersama Windows, atau ekspor NFS,** memerlukan pembantu milik Trindle.

## Drive tidak mau dibuka atau disimpan
Questions: mengapa drive USB saya tidak mau terbuka; apa arti drive ini sedang berubah; apa arti drive tidak dapat dijangkau saat ini; mengapa drive tidak bisa disimpan; mengapa drive terenkripsi saya tidak mau dibuka kuncinya

Folders membuka drive untuk Anda dari bilah samping atau dari kartunya di halaman Penyimpanan. Jika drive dikunci dengan kata sandi, Folders membuka kuncinya lebih dulu, lalu membukanya sebagai Anda. Menyimpan drive adalah kebalikannya. Folders menutupnya, mengunci lagi bila terenkripsi, dan mematikannya setelah tidak ada lagi yang terbuka di drive itu. Hanya drive yang dicolokkan yang bisa disimpan. Disk di dalam komputer tidak pernah bisa.

![Halaman Penyimpanan di Folders dengan dua kartu, Disk sistem dan drive USB bernama HOLIDAY yang tidak di-mount. Di bagian bawah, kata-kata merah menyatakan HOLIDAY tidak dapat dibuka, dengan alasannya dan tombol Selengkapnya bulat.](img/folders-drive-open-failed.png "Yang akan Anda lihat: halaman Penyimpanan setelah sebuah drive tidak mau terbuka. Kata-kata merah ada di bagian bawah.")

- **Drive ini sedang berubah. Buka lagi setelah selesai.** Drive sedang dibuka atau disimpan. Tunggu sampai selesai, lalu coba lagi.
- **Drive tidak dapat dijangkau saat ini.** Folders berbicara dengan layanan drive komputer (UDisks) dan layanan itu tidak menjawab. Coba lagi sebentar lagi. Jika terus terjadi, mulai ulang komputer.
- **HOLIDAY tidak dapat dibuka**, dengan sebab di belakangnya. Sebabnya datang dari layanan drive, jadi memakai kata-katanya. Jika drive terkunci, pastikan Anda mengetik kata sandi yang benar.
- **HOLIDAY tidak dapat disimpan**, dengan sebab di belakangnya. Jika sebabnya menyebut ada yang memakai drive, tutup folder dan file yang Anda buka di dalamnya, lalu coba lagi.

Sebelum drive disimpan, setiap panel yang menampilkannya berpindah darinya, jadi tidak ada yang menahannya terbuka di Folders.

:::expert
Drive dibuka dan disimpan lewat UDisks. Drive di-mount sebagai Anda, lalu dibuka. Drive yang dicolokkan di-unmount, dikunci lagi bila terenkripsi, dan dimatikan setelah tidak ada lagi yang terbuka di drive itu.
:::

## Server tidak menjawab
Questions: mengapa Folders tidak bisa menemukan server saya; apa arti tidak ditemukan server dengan nama itu; mengapa dikatakan server tidak menjawab; apa arti menolak sambungan; mengapa sambungan ke server terputus; mengapa dikatakan alamat itu tidak bisa dibaca; apa arti tidak ada jalan untuk menjangkaunya

Folders menjangkau komputer lain lewat alamatnya, seperti `sftp://jo@example.com`. Sebelum meminta login, Folders harus bisa sampai ke komputer itu dulu. Saat tidak bisa, kata-kata merah menyebutkan sampai sejauh mana.

![Kartu Hubungkan ke server dengan alamat sftp://jo@nas.example.com yang diketik. Kata-kata merah di bawah kotak menyatakan tidak ada server bernama nas.example.com yang ditemukan, dengan tombol Selengkapnya bulat.](img/folders-server-no-answer.png "Yang akan Anda lihat: kartu Hubungkan ke server saat tidak ada server dengan nama itu yang ditemukan.")

- **Tidak ditemukan server dengan nama itu.** Nama itu tidak dikenal jaringan Anda. Periksa ejaannya. Jika itu komputer di rumah Anda, coba nomornya, seperti `192.168.1.20`.
- **Sambungan ditolak.** Komputernya ada, tetapi tidak ada yang menunggu jenis sambungan ini di port itu. Program server mungkin mati, atau port-nya berbeda. Tambahkan port ke alamat, seperti `sftp://jo@nas.example.com:2222`.
- **Tidak menjawab.** Folders menunggu dan tidak mendengar apa pun. Komputer mungkin tertidur atau mati, atau ada di jaringan lain. Folders menunggu sekitar 20 detik sebelum menyerah.

![Kartu Hubungkan ke server dengan alamat ftp://jo@nas.example.com yang diketik. Kata-kata merah menyatakan nas.example.com tidak menjawab, dengan tombol Selengkapnya bulat.](img/folders-server-did-not-answer.png "Yang akan Anda lihat: kartu saat sebuah server tidak menjawab.")

- **Tidak ada jalan untuk menjangkaunya.** Sesuatu di antara Anda dan komputer itu, seperti firewall atau jaringan yang mati, menghentikan sambungan.

![Kartu Hubungkan ke server dengan alamat sftp://jo@nas.example.com. Kata-kata merah menyatakan sambungan ke server terputus, dengan tombol Selengkapnya bulat.](img/folders-server-lost.png "Yang akan Anda lihat: kartu saat tautan ke sebuah server terputus.")

- **Sambungan ke server terputus, server berhenti menjawab, atau server menutup sambungan.** Tautan berfungsi lalu putus. Buka tempat itu lagi. Apa pun yang terkirim separuh tidak disimpan sebagai file utuh: salinan ke server diperiksa sebelum yang lama diganti.
- **Server mengirim pesan yang tidak bisa dibaca.** Server dan Folders tidak lagi sepaham. Buka lagi. Jika terus terjadi, [laporkan masalah](report-a-problem.html).
- **Alamat itu tidak bisa dibaca.** Kata-kata sesudahnya menyebutkan sebabnya: tidak ada `sftp://`, `ftp://` atau `mtp://` di awal; hanya `sftp://`, `ftp://`, `ftps://`, `ftpes://`, `dav://`, `davs://`, `smb://`, `nfs://` dan `mtp://` yang bisa dibuka; ada `[` tanpa `]`; tidak menyebut server; nama server bukan sebuah nama; path berisi pemisah baris; ada sesuatu setelah nama server; atau yang ada setelah titik dua bukan port.
- **Alamat server tidak diketahui.** Salinan file dari server tersimpan, tetapi Folders tidak lagi bisa mengetahui dari server mana asalnya.

:::expert
SFTP berjalan di dalam program `ssh` Anda sendiri dengan waktu sambung 20 detik, jadi yang dikatakan Folders di sini adalah yang ditemukan `ssh`, dalam kata-kata biasa. FTP dan WebDAV tersambung langsung dari Folders, mencoba tiap alamat yang diberikan nama itu. Server FTP aman yang namanya tidak bisa dimuat dalam sertifikat ditolak.
:::

## Server tidak mengizinkan Anda masuk
Questions: mengapa Folders meminta saya memercayai server; apa arti tidak lagi punya identitas yang dulu dimilikinya; mengapa dikatakan server meminta kata sandi atau kunci; apa arti sertifikat tidak bisa diperiksa; mengapa kata sandi saya tidak dikirim; mengapa server tidak menerima login itu; apa itu sidik jari

Folders berhati-hati terhadap siapa yang diajaknya bicara, karena apa yang Anda ketik sampai ke siapa pun yang menjawab. Inilah saat-saat Folders berhenti dan memberi tahu Anda sebabnya.

![Kartu Hubungkan ke server untuk nas.example.com, server yang belum pernah dikunjungi, dengan peringatan tentangnya dan tombol Percayai dan hubungkan.](img/folders-server-trust.png "Yang akan Anda lihat: kartu Hubungkan ke server untuk server yang baru pertama kali terlihat.")

- **Belum pernah dikunjungi.** Folders tidak bisa memastikan itu komputer yang benar. Jika Anda memang ingin menjangkaunya, tekan **Percayai dan hubungkan**. Folders mengingatnya, seperti ssh.
- **Tidak lagi punya identitas yang dulu dimilikinya.** Ini merah karena ini yang harus ditanggapi dengan serius. Komputer mungkin dibangun ulang, atau ada pihak lain yang menghalangi. Folders tidak membukanya. Jika pemiliknya mengubahnya, hapus yang lama dari known hosts Anda lebih dulu, lalu coba lagi.

![Kartu Hubungkan ke server untuk nas.example.com. Kata-kata merah menyatakan server itu tidak lagi memiliki identitas yang dimilikinya sebelumnya, bahwa seseorang mungkin menghalangi, dan bahwa server tidak dibuka, dengan tombol Selengkapnya bulat.](img/folders-server-identity-changed.png "Yang akan Anda lihat: kartu saat identitas sebuah server berubah.")

- **Server ini meminta kata sandi.** Ketik di kotak kata sandi pada kartu lalu tekan **Hubungkan**.
- **Server ini meminta kunci atau kata sandi.** Sebutkan file kunci Anda di kartu, atau tambahkan kunci ke agen ssh Anda, lalu coba lagi. Untuk ssh, kata sandi atau frasa sandi kunci diminta di jendela kecil milik Trindle sendiri.
- **Server tidak menerima login itu.** Nama pengguna, kata sandi, atau kuncinya tidak benar.
- **Kunci tidak ada.** File kunci yang disebut di kartu tidak ada, atau berada di tempat yang tidak pernah dilihat Trindle.

![Kartu Hubungkan ke server untuk nas.example.com dengan kotak untuk berkas kunci. Kata-kata merah meminta kunci atau kata sandi, dengan tombol Selengkapnya bulat.](img/folders-server-needs-key.png "Yang akan Anda lihat: kartu saat sebuah server meminta kunci atau kata sandi.")

- **Sertifikat tidak bisa diperiksa.** Server FTP aman membuktikan jati dirinya dengan sertifikat. Sertifikat itu gagal dalam pemeriksaan biasa karena salah satu sebab ini: komputer ini tidak punya sertifikat tepercaya untuk memeriksanya; tidak ditandatangani oleh pihak yang dipercaya komputer ini, seperti sertifikat yang dibuat server untuk dirinya sendiri; sudah kedaluwarsa; belum berlaku; dibuat untuk nama yang berbeda; sudah dicabut; atau tidak lolos pemeriksaan biasa. Jika bisa, bandingkan sidik jari di kartu dengan yang diberikan pemilik server, dan percayai hanya bila cocok.
- **Sertifikat bukan yang Anda percayai sebelumnya.** Pemiliknya mungkin memperbaruinya, atau ada pihak lain yang menghalangi. Percayai yang baru hanya bila pemiliknya mengonfirmasi sidik jari ini.
- **Server menjawab di alamat yang hanya terdengar di jaringan.** Perangkat mana pun di jaringan bisa menjawab sebuah nama, jadi kata sandi belum dikirim. Jika alamat itu benar, tekan **Hubungkan**. Folders mengatakan ini di kartu, dan lagi dengan warna merah bila pekerjaan dengan server itu berhenti karena tautannya terputus.

![Kartu Hubungkan ke server untuk server FTP aman, nas.example.com, dengan sidik jari AB:CD:12:34:56:78 ditampilkan dan peringatan bahwa sertifikatnya bukan yang dipercayai sebelumnya.](img/folders-server-cert-changed.png "Yang akan Anda lihat: kartu saat sertifikat sebuah server bukan yang dipercayai sebelumnya.")

Sidik jari adalah kode pendek yang mewakili satu sertifikat atau satu identitas komputer. Dua yang cocok adalah hal yang sama.

:::expert
Server SFTP yang dipercaya masuk ke known hosts ssh biasa Anda, dan yang berubah ditolak dengan pemeriksaan host ketat, jadi Folders tidak pernah menimpa penolakan ssh sendiri. Sertifikat FTP aman yang dipercaya diingat lewat sidik jarinya untuk server itu, dan hanya sertifikat itu persis yang diloloskan. Kata sandi untuk FTP atau WebDAV dikirim ke alamat yang dipakai saat mengetiknya dan tidak ke yang lain.
:::

## Server tidak mau melakukannya
Questions: mengapa server menolak salinan saya; apa arti server tidak bisa melakukannya; mengapa dikatakan izin ditolak; apa arti sudah ada; mengapa sambungan aman gagal; mengapa ssh tidak terpasang; mengapa file dikatakan terpotong

Komputer menjawab dan mengizinkan Anda masuk, lalu tidak mau melakukan yang diminta, atau tautan aman tidak bisa dibuat. Kata-kata merah memberikan alasan server dalam kata-kata biasa. Bila berupa daftar item dari penyalinan, pemindahan, atau penghapusan, tiap item punya sebabnya dalam kurung, seperti di [Pekerjaan yang tidak selesai](folders.html#work-that-did-not-finish).

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan satu item tidak dapat disalin, report.odt, karena izin ditolak untuk report.odt, dengan tombol Selengkapnya bulat di kanan.](img/folders-server-refused.png "Yang akan Anda lihat: bagian bawah jendela setelah penyalinan ke server ditolak.")

Yang mungkin dikatakan server:

- **Tidak ada / sudah ada.** Itu dipindahkan atau dibuat orang lain saat Anda bekerja.
- **Izin ditolak.** Akun Anda di server mungkin tidak boleh melakukannya di folder itu.
- **Sedang dipakai program lain.** Coba lagi setelah program lain selesai.
- **Belum didukung / server tidak bisa melakukannya dengan itu.** Server tidak menawarkan tindakan itu, atau menolak tanpa sebab yang lebih jelas. Bila server memberi sebab, sebab itu menyusul.
- **Server penuh.** Tidak ada ruang tersisa untuk file.
- **Folder tidak kosong.** Folder yang berisi sesuatu tidak dihapus oleh tindakan ini. Hapus dulu isinya.
- **Itu file, bukan folder.** Alamat berakhir pada sebuah file.
- **File datang terpotong, berakhir sebelum semuanya terkirim, atau salinan yang dikirim bukan panjang yang seharusnya.** Transfer tidak selesai utuh, jadi file lama dipertahankan.

![Kartu Hubungkan ke server dengan alamat dav://jo@nas.example.com. Kata-kata merah menyatakan server penuh, dengan tombol Selengkapnya bulat.](img/folders-server-full.png "Yang akan Anda lihat: kartu saat sebuah server menyatakan penuh.")

- **Daftar folder tidak bisa dibaca.** Server menjawab dengan cara yang tidak bisa dibaca Folders.
- **Server tidak mendaftar folder lewat WebDAV di sini, tidak menjawab sebagai server web, atau meminta jenis login yang tidak dikenal Folders.** Alamatnya mungkin bukan alamat WebDAV. Periksa dengan pemilik server.
- **Sambungan aman tidak bisa disiapkan, dimulai, atau diselesaikan.** Server berhenti menjawab atau menutup tautan saat tautan dibuat. Coba lagi. Jika terus gagal, coba alamat yang sama dengan `ftp://` di depannya, tetapi hanya bila Anda menerima bahwa tidak ada yang terlindungi.

![Kartu Hubungkan ke server dengan alamat ftps://jo@nas.example.com. Kata-kata merah menyatakan sambungan aman tidak dapat disiapkan karena server menutup tautan, dengan tombol Selengkapnya bulat.](img/folders-server-secure-failed.png "Yang akan Anda lihat: kartu saat sambungan aman tidak dapat dibuat.")

- **Server ini tidak menawarkan FTP aman.** Coba alamat dengan `ftp://` di depannya. Tidak ada yang dikirim dengan cara itu yang terlindungi.
- **Server tidak mau melindungi transfer file, jadi tidak ada yang dikirim.** Folders menolak mengirim file tanpa perlindungan bila Anda memintanya dilindungi.
- **Server tidak menyambut kami.** Server menjawab, tetapi tidak memberikan sambutan yang diberikan server FTP.
- **Program ssh tidak terpasang, atau ssh tidak bisa dijalankan.** SFTP memerlukan ssh. Pasang, lalu coba lagi.
- **SFTP tidak ada di server ini, atau jenisnya lama.** Server mungkin menawarkan jalan masuk lain, seperti FTP.

![Kartu Hubungkan ke server dengan alamat ftp://jo@nas.example.com. Kata-kata merah menyatakan server tidak menyambut kita dan menyebut apa yang dikatakannya, dengan tombol Selengkapnya bulat.](img/folders-server-no-welcome.png "Yang akan Anda lihat: kartu saat server FTP tidak memberikan sambutannya.")

- **Dibiarkan: berubah tepat sebelum dihapus.** WebDAV menghapus file hanya bila masih yang dilihat Folders.
- **Dua file mungkin diberi satu nama.** Server FTP biasa tidak bisa menolak nama yang sudah dipakai, jadi Folders melihat dulu dan mengatakan hanya itu yang bisa dilakukannya.
- **Tidak semuanya sampai, jadi masih di tempat semula.** Pemindahan menyingkirkan aslinya hanya bila salinannya utuh.
- **Tautan, pipa, perangkat, atau soket tidak dikirim.** Folders hanya mengirim file dan folder.
- **Yang lama tidak bisa dihapus, dan ada utuh dengan nama lain.** Saat pengganti dipasang, file lama disimpan aman bila tidak bisa dihapus.

:::expert
File server ditulis dengan nama sementara dan baru dipasang bila panjangnya benar. Bila pemindahan antar drive terpotong, aslinya tetap ada. WebDAV menghapus dengan syarat pada ukuran dan waktu file, jadi file yang berubah sementara itu dibiarkan. FTP biasa tidak bisa disuruh menolak nama yang sudah dipakai, jadi nama dilihat dulu, yang menyisakan sesaat di mana orang lain bisa mengambilnya.
:::

## Ponsel tidak menampilkan file-nya
Questions: mengapa ponsel saya tidak muncul di Folders; mengapa dikatakan ponsel tidak menampilkan penyimpanan; bagaimana cara membuat ponsel saya menampilkan file-nya; apa arti izin untuk sambungan USB ponsel ditolak; mengapa ponsel berhenti menjawab

Ponsel, tablet, dan kamera muncul di bilah samping dengan sendirinya setelah dicolokkan dan dibuka kuncinya. Anda tidak mengetik alamat untuk itu. Folders berbicara dengan ponsel lewat kabel USB.

![Panel Folders untuk ponsel bernama Pixel. Kata-kata merah menyatakan ponsel tidak menampilkan penyimpanan dan meminta Anda membuka kuncinya lalu memilih Transfer berkas, dengan tombol Coba lagi dan tombol Selengkapnya bulat di sampingnya.](img/folders-phone-no-storage.png "Yang akan Anda lihat: panel untuk ponsel yang tidak menampilkan penyimpanan.")

- **Ponsel tidak menampilkan penyimpanan.** Buka kunci ponsel dan pilih **File transfer** untuk sambungan USB. Lalu coba lagi.
- **Ponsel itu tidak tercolok / ponsel dicabut.** Kabel terlepas, atau ponsel tertidur. Colokkan dan buka kuncinya.

![Panel Folders untuk ponsel bernama Pixel. Kata-kata merah menyatakan izin ditolak untuk sambungan USB ponsel, dengan tombol Coba lagi dan tombol Selengkapnya bulat.](img/folders-phone-refused.png "Yang akan Anda lihat: ponsel yang sambungan USB-nya ditolak.")

- **Izin untuk sambungan USB ponsel ditolak.** Trindle tidak diizinkan memakai perangkat USB itu. Cabut ponsel, colokkan lagi, dan coba lagi. Jika tetap ditolak, [laporkan masalah](report-a-problem.html).
- **Ponsel sedang dipakai program lain.** Program lain membuka ponsel itu. Tutup, lalu coba lagi.
- **Ponsel berhenti menjawab, menolak itu, atau hanya menerima sebagian dari yang dikirim.** Tautan terputus di tengah jalan, atau ponsel menolak. Coba lagi, dan periksa file di ponsel.
- **Ponsel mengirim sesuatu yang tidak masuk akal.** Cabut, colokkan, dan buka lagi.
- **Ponsel penuh, atau file lebih pendek dari yang dikatakannya.** Kosongkan ruang di ponsel, dan salin lagi filenya.

![Panel Folders untuk ponsel bernama Pixel. Kata-kata merah menyatakan ponsel penuh, dengan tombol Coba lagi dan tombol Selengkapnya bulat.](img/folders-phone-full.png "Yang akan Anda lihat: ponsel yang tidak punya ruang lagi.")

- **File dan folder hanya bisa masuk ke dalam salah satu penyimpanan ponsel.** Buka satu penyimpanan, seperti yang internal, dan taruh barang di sana.
- **Itu bukan folder, itu folder, atau tidak kosong.** Tindakan tidak cocok dengan yang ada. Folder dihapus hanya bila kosong.
- **Satu penyimpanan utuh tidak bisa dihapus atau diganti namanya.** Folders tidak mau melakukan keduanya.
- **Ponsel menolak itu (kode 2xxx).** Ponsel tidak memberi sebab dalam kata-kata, hanya angka. Angka itu membantu [laporan](report-a-problem.html).

:::expert
Folders berbicara MTP dan PTP biasa sendiri lewat USB, tanpa bantuan layanan file sistem.
:::

## Nama ditolak
Questions: mengapa Folders tidak mau menerima nama itu; apa arti nama tidak boleh berisi garis miring; mengapa dikatakan server mengirim nama tidak aman; mengapa nama dilewati; apa arti nama itu disediakan untuk sistem

Folders memeriksa setiap nama sebelum memakainya, baik yang Anda ketik maupun yang dikirim server. Nama yang tidak mau dipakainya dinyatakan dengan warna merah, dan tidak ada yang diganti namanya atau dibuat dengannya.

![Panel Folders dengan kotak ganti nama terbuka pada notes.txt. Kata-kata merah di bagian bawah menyatakan Nama tidak boleh berisi garis miring, dengan tombol Selengkapnya bulat di sampingnya.](img/folders-name-refused.png "Yang akan Anda lihat: penggantian nama yang ditolak. Kata-kata merah ada di bagian bawah.")

Nama yang Anda ketik:

- **Nama tidak boleh kosong.**
- **Nama tidak boleh berisi garis miring.** Garis miring memisahkan folder, jadi tidak bisa menjadi bagian dari nama.
- **Nama itu disediakan untuk sistem.** Satu titik atau dua titik berarti folder itu sendiri dan folder di atasnya.
- **Nama itu terlalu panjang.** Tidak ada nama yang boleh lebih dari 255 byte. Huruf di luar bahasa Inggris mungkin memakai lebih dari satu byte masing-masing.
- **File atau folder dengan nama itu sudah ada di sini.** Pilih nama lain, atau ganti nama atau pindahkan yang ada.
- **Tidak bisa diganti namanya, dengan sebab.** Namanya baik-baik saja, tetapi disk atau folder tidak mengizinkan perubahan. Anda mungkin tidak boleh menulis di folder itu, atau disk hanya-baca.

![Panel Folders dengan kotak ganti nama terbuka pada notes.txt, kini kosong. Kata-kata merah di bagian bawah menyatakan Nama tidak boleh kosong, dengan tombol Selengkapnya bulat di sampingnya.](img/folders-name-empty.png "Yang akan Anda lihat: kotak ganti nama yang dibiarkan kosong.")

Nama yang dikirim server:

- **Dilewati: server mengirim nama tidak aman.** Server bisa mengirim nama yang bukan satu nama biasa, seperti nama dengan garis miring yang akan memanjat keluar dari folder. Folders tidak akan membuat baris untuknya, karena apa pun yang Anda lakukan dengannya bisa menjangkau tempat yang tidak Anda maksud. Sisa folder ditampilkan. Jika beberapa dilewati, kata-kata menyebutkan berapa banyak dan menyebut namanya.
- **Sesuatu tanpa nama** dikeluarkan dengan cara yang sama.

:::expert
Nama dari server harus satu nama biasa sebelum dipakai di komputer ini, di mana nama itu bisa menjadi bagian dari sebuah path. Pemeriksaan yang sama dilakukan untuk nama file server yang diambil untuk dibuka, dan untuk nama server itu sendiri.
:::

## Folder bersama meminta login
Questions: mengapa Folders meminta nama pengguna dan kata sandi untuk folder bersama; mengapa dikatakan nama pengguna atau kata sandi tidak benar; apa arti login yang tersimpan untuknya belum dikirim; mengapa Folders bertanya lagi untuk folder bersama yang saya ingat; apa arti keyring tidak bisa dijangkau; mengapa login saya tidak tersimpan

Folder bersama di komputer Windows atau NAS (folder bersama SMB) sering meminta nama pengguna dan kata sandi. Itu untuk akun di komputer lain itu, bukan untuk komputer Anda. Folders memintanya di kartu kecil bernama **Buka** dan nama folder bersama itu.

![Kartu Buka untuk berbagi bernama Photos di komputer NAS-HOME, dengan kotak nama pengguna, kotak kata sandi dan tombol Buka. Kata-kata merah di bagian atas menyatakan nama pengguna atau kata sandi tidak benar, dengan tombol Selengkapnya bulat.](img/folders-share-login-card.png "Yang akan Anda lihat: kartu yang meminta login sebuah berbagi setelah satu login ditolak.")

Saat kartu mengatakan ada yang salah, itu salah satu dari ini.

- **Nama pengguna atau kata sandi tidak benar.** Ketik lagi. Nama pengguna di komputer Windows mungkin memerlukan workgroup-nya di depan, seperti `WORKGROUP\jo`.
- **Akun itu mungkin tidak boleh membukanya.** Login benar, tetapi akun itu tidak berhak atas folder bersama ini. Tanyakan kepada yang mengurus komputer itu.
- **Akun Anda terkunci atau dimatikan, atau kata sandinya sudah habis masa berlakunya.** Perbaiki ini di komputer lain. Folders tidak bisa.

![Kartu Buka untuk Photos di NAS-HOME. Kata-kata merah menyatakan NAS-HOME menjawab di alamat yang berbeda dari tempat login tersimpan dipakai, jadi login tidak dikirim, dengan tombol Selengkapnya bulat.](img/folders-share-login-held.png "Yang akan Anda lihat: kartu saat login tersimpan ditahan.")

- **Login yang Anda simpan tidak dikirim.** Folders menyimpan login yang Anda pilih untuk diingat selama 90 hari, dan hanya mengirimnya ke alamat yang pernah dipakai sebelumnya. Jika komputer sekarang menjawab di alamat yang berbeda, di alamat yang tidak bisa ditemukan Folders sebelumnya, atau yang hanya terdengar di jaringan, login yang tersimpan tidak dikirim, karena perangkat mana pun di jaringan bisa menjawab sebuah nama. Kartu menyebutkan yang mana, dan menunjukkan ke mana ketikan Anda akan pergi. Jika itu komputer Anda, ketik nama pengguna dan kata sandinya lalu tekan **Buka**. Jika Anda tidak akan memakai alamat lama lagi, nyalakan **Lupakan alamat sebelumnya**. Hanya delapan alamat terakhir tempat login dipakai yang diingat.
- **Terbuka, tetapi login tidak tersimpan.** Folder bersama terbuka, dan keyring tidak menyimpan login Anda. Kata-kata sesudahnya menyebutkan sebabnya.
- **Keyring tidak bisa dijangkau.** Folders menyimpan login yang diingat di keyring Anda. Jika keyring tidak bisa ditanya, kartu mengatakannya dengan warna merah, agar keyring terkunci tidak dikira login tidak tersimpan. Buka kunci keyring, atau keluar lalu masuk lagi, lalu coba lagi.

Keterangan lebih lanjut tentang login yang diingat ada di [Folder bersama meminta login lagi](troubleshooting.html#a-shared-folder-asks-for-a-login-again).

![Kartu Buka untuk Photos di NAS-HOME. Kata-kata merah menyatakan gantungan kunci tidak menjawab tepat waktu, dengan tombol Selengkapnya bulat.](img/folders-share-keyring.png "Yang akan Anda lihat: kartu saat gantungan kunci tidak dapat dijangkau.")

:::expert
Login yang tersimpan disimpan di keyring atas nama komputer dan folder bersama yang dituju, dan item kedua mengingat alamat tempat login itu dipakai, dengan waktunya masing-masing. Login itu diberikan ke pembantu administrator Trindle lewat input standarnya, yang menuliskannya ke file yang hanya bisa dibaca administrator dan menghapus file itu bila mount selesai. Tidak ada login yang dikirim ke nama saja: login pergi ke alamat yang ditampilkan kartu, dan tidak ke yang lain.
:::

## Folder bersama tidak mau terbuka
Questions: mengapa folder bersama jaringan saya tidak mau terbuka; apa arti tidak ditemukan komputer dengan nama itu; mengapa dikatakan komputer tidak menjawab; apa arti hanya berbicara SMB1; apa arti tidak menawarkan NFS versi 4; mengapa smbclient tidak terpasang; apa arti tidak membagikan apa pun bernama; mengapa folder bersama tidak bisa ditutup

Folders membuka folder bersama Windows (`smb://`) atau ekspor NFS (`nfs://`) dengan me-mount-nya, sehingga tampil sebagai folder biasa. Saat itu tidak bisa dilakukan, kata-kata merah menyebutkan sebabnya.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan NAS-HOME tidak menjawab dan mungkin sedang tidur atau mati, dengan tombol Selengkapnya bulat di kanan.](img/folders-share-not-opened.png "Yang akan Anda lihat: bagian bawah jendela saat komputer sebuah berbagi tidak menjawab.")

- **Tidak ditemukan komputer dengan nama itu di jaringan ini.** Periksa ejaannya, atau pakai nomornya, seperti `smb://192.168.1.20`.
- **Tidak menjawab. Mungkin tertidur atau mati.** Bangunkan, pastikan ada di jaringan yang sama, lalu coba lagi.
- **Hanya berbicara SMB1.** SMB1 adalah cara berbagi lama yang tidak lagi aman, jadi Trindle tidak memakainya. Nyalakan versi yang lebih baru di komputer atau NAS itu.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan NAS-HOME tidak punya folder bersama bernama Photos, dengan tombol Selengkapnya bulat di kanan.](img/folders-share-not-found.png "Yang akan Anda lihat: komputer yang tidak punya berbagi dengan nama itu.")

- **Tidak punya folder bersama dengan nama itu.** Komputer menjawab, tetapi tidak membagikan apa pun dengan nama itu. Untuk NFS, kata-katanya adalah "tidak membagikan apa pun bernama" path yang Anda ketik. Buka komputernya saja untuk melihat apa yang dibagikannya.
- **Tidak mengizinkan komputer ini membukanya.** Untuk NFS, daftar server tentang siapa yang boleh memakai ekspor tidak mencakup komputer ini. Tambahkan di server.
- **Tidak menawarkan NFS versi 4.** Trindle hanya membuka versi 4. Lihat [Alamat nfs:// tidak mau terbuka](troubleshooting.html#an-nfs-address-does-not-open).

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan program yang diperlukan untuk membuka berbagi tidak terpasang, dengan tombol Selengkapnya bulat di kanan.](img/folders-share-program-missing.png "Yang akan Anda lihat: berbagi yang memerlukan program yang tidak terpasang.")

- **Ini memerlukan program yang tidak terpasang.** Kata-katanya menyebut paket Debian, seperti smbclient. Pasang pembaruan yang menunggu, atau pasang paket itu.
- **Kata sandi administrator tidak diberikan.** Me-mount folder bersama memerlukannya. Coba lagi dan ketik saat diminta.
- **Itu bukan nama komputer, atau path folder bersama.** Alamat berisi sesuatu yang tidak bisa dimuat nama komputer atau path NFS.
- **Terbuka, tetapi tidak diketahui di mana.** Folder bersama sudah di-mount dan Folders tidak bisa mengetahui letaknya. Buka halaman Jaringan lagi.
- **Folder bersama tidak bisa ditutup.** Ada sesuatu di dalamnya yang masih dipakai. Tutup folder dan file yang Anda buka di dalamnya, lalu coba lagi.

:::expert
Folder bersama Windows di-mount dengan `mount.cifs` dan daftarnya dibuat dengan `smbclient`. Ekspor NFS di-mount dengan `mount.nfs` pada versi 4. Kedua mount lewat pembantu administrator Trindle, yang meminta kata sandi administrator, dan mount berada di bawah folder folder bersama milik Anda sendiri. Kata-katanya berasal dari membaca apa yang dikatakan program-program itu.
:::

## Folder tidak bisa dibagikan
Questions: mengapa saya tidak bisa membagikan folder ini; apa arti hanya folder milik Anda yang bisa dibagikan; mengapa dikatakan nama itu sudah dipakai; mengapa kata sandi berbagi ditolak; apa arti nama folder bersama tidak boleh berisi; mengapa Samba perlu disiapkan

Bagikan folder ini, di Properti sebuah folder, memungkinkan komputer lain di rumah membukanya, termasuk komputer Windows. Folders menolak dalam kasus berikut.

![Bagian Bagikan di Properti untuk folder bernama Albums. Kata-kata merah menyatakan folder bersama Anda yang lain sudah memakai nama itu dan meminta Anda memilih nama lain, dengan tombol Selengkapnya bulat.](img/folders-sharing-refused.png "Yang akan Anda lihat: bagian Bagikan di Properti setelah sebuah nama ditolak.")

- **Folder ini tidak bisa dibaca.** Folders tidak bisa melihatnya, jadi tidak bisa membagikannya.
- **Hanya folder itu sendiri yang bisa dibagikan, bukan tautan ke folder.** Bagikan folder yang dituju tautan itu.

![Bagian Bagikan di Properti untuk folder bernama Albums. Kata-kata merah menyatakan hanya folder milik Anda yang dapat dibagikan dan folder ini milik orang lain, dengan tombol Selengkapnya bulat.](img/folders-sharing-not-yours.png "Yang akan Anda lihat: bagian Bagikan di Properti untuk folder yang bukan milik Anda.")

- **Hanya folder milik Anda yang bisa dibagikan.** Yang ini milik orang lain.
- **Folder bersama Anda yang lain sudah memakai nama itu.** Pilih nama lain.
- **Nama tidak diizinkan.** Nama tidak boleh kosong, paling banyak 80 huruf, dan tidak boleh berisi salah satu dari `% < > * ? | / \ + = ; : "` atau koma. Nama tidak boleh berakhir dengan `$`, yang akan menyembunyikan folder bersama, dan Samba menyimpan `global`, `homes`, `printers`, `print$` dan `ipc$` untuk dirinya sendiri.

![Bagian Bagikan di Properti untuk folder bernama Albums. Kata-kata merah menyatakan kata sandi membutuhkan paling sedikit 8 huruf, dengan tombol Selengkapnya bulat.](img/folders-sharing-password-short.png "Yang akan Anda lihat: bagian Bagikan di Properti setelah kata sandi yang terlalu pendek.")

- **Kata sandi memerlukan paling sedikit 8 huruf.** Kata sandi berbagi adalah yang dipakai komputer lain untuk masuk. Kata sandi ini terpisah dari kata sandi login Anda.
- **Komputer lain belum bisa menjangkaunya.** Ini tidak merah. **Izinkan komputer lain terhubung** mati di Pengaturan, Jaringan. Tombol di samping kata-kata itu menyalakannya setelah kata sandi administrator.

Saat pertama kali Anda berbagi, Trindle mengambil Samba, program yang membagikan folder, dan menyiapkannya. Ini meminta kata sandi administrator lebih dulu dan memakan waktu sekitar satu menit. Kegagalan saat itu dinyatakan dengan kata-kata merah di bawah sakelar.

:::expert
Folder bersama dibuat dengan `net usershare`, yang hanya pernah menawarkan folder milik Anda, dengan sebuah nama, apakah orang lain boleh mengubah file, dan apakah tamu tidak memerlukan kata sandi. Tidak ada kata sandi yang pernah menjadi bagian dari folder bersama. Folder bersama yang ditawarkan kepada tamu juga memerlukan folder di atasnya terbuka bagi akun lain untuk jalan lewat, itulah yang dilakukan **Izinkan pengunjung lewat ke folder ini**.
:::

## File tidak bisa dibaca
Questions: mengapa Folders tidak bisa menampilkan gambar saya; mengapa dikatakan ini tidak bisa diputar; apa arti mungkin rusak atau terpotong; mengapa gambar terlalu besar untuk ditampilkan; mengapa pratinjau mengatakan tidak bisa dibaca; mengapa ffmpeg perlu dipasang; mengapa checksum tidak bisa dihitung

Panel pratinjau, penampil, dan baris Checksum di Properti membaca file untuk menampilkannya. Saat tidak bisa, semuanya menyebutkan sebabnya dengan singkat, dengan **Lainnya** yang tenang di sebelahnya.

![Penampil terbuka pada holiday.png, sebuah gambar. Tertulis Gambar ini terlalu besar untuk ditampilkan di sini: 150 juta piksel, dengan tombol Selengkapnya bulat dan tombol Buka di aplikasinya.](img/folders-file-unread.png "Yang akan Anda lihat: penampil saat gambar terlalu besar untuk ditampilkan.")

- **File ini sudah tidak ada.** File dipindahkan atau dihapus setelah Folders menampilkannya. Lihat folder lagi.
- **Anda tidak punya izin untuk membaca file ini.** File milik orang lain, atau pemiliknya menutupnya bagi Anda. Tanyakan kepada pemiliknya.
- **File ini tidak bisa dibaca, dengan sebab di belakangnya.** Disk atau komputer lain memberikan sebabnya dengan kata-katanya sendiri.

![Penampil terbuka pada broken.pdf. Tertulis namanya menyatakan dokumen PDF tetapi isinya bukan, dan mungkin rusak atau terpotong, dengan tombol Selengkapnya bulat dan tombol Buka di aplikasinya.](img/folders-file-broken.png "Yang akan Anda lihat: penampil saat berkas bukan seperti yang dikatakan namanya.")

- **Namanya mengatakan ini gambar, tetapi isinya bukan. Mungkin rusak atau terpotong.** Di sini Folders lebih memercayai nama daripada isi, jadi unduhan yang terpotong mengatakannya, bukan tampak seperti teks aneh. Ambil lagi filenya.
- **Gambar ini tidak bisa dibaca.** Gambar rusak, atau jenis yang tidak bisa dibuka Folders.
- **Gambar ini terlalu besar untuk ditampilkan di sini.** Folders tidak membuka file gambar yang lebih besar dari 100 MB, atau yang punya lebih dari 120 juta piksel, sekecil apa pun filenya. Buka di aplikasi gambar.
- **Ini tidak bisa diputar. Mungkin rusak, atau jenis yang tidak bisa diputar ffmpeg.** Coba file itu di pemutar lain.
- **Video dan suara diputar oleh ffmpeg, yang tidak terpasang di komputer ini.** Pasang ffmpeg dan coba lagi.
- **Halaman N tidak bisa digambar.** Satu halaman PDF tidak bisa digambar. PDF mungkin rusak.
- **Sisanya tidak bisa dibaca.** File teks panjang dibaca per bagian. Bagian berikutnya yang Anda minta tidak bisa dibaca.
- **Tidak bisa diambil.** File ada di server dan salinannya tidak mau datang. Lihat [Server tidak mau melakukannya](folders.html#a-server-would-not-do-that).

![Penampil terbuka pada broken.ttf. Tertulis tidak dapat dibaca karena bukan font yang dapat dibaca Folders, dengan tombol Selengkapnya bulat dan tombol Buka di aplikasinya.](img/folders-file-font.png "Yang akan Anda lihat: penampil saat sebuah font tidak dapat dibaca.")

- **Bukan font yang bisa dibaca Folders, atau terlalu besar untuk ditampilkan.** Ini untuk halaman contoh font.
- **File tidak bisa dibaca** di sebelah Checksum. Jumlah dihitung dari seluruh file, jadi tidak ada yang bisa ditampilkan.

:::expert
Gambar, teks, dan font dibaca oleh Folders sendiri. Suara, video, dan PDF diserahkan ke program lain dan tidak pernah dibaca oleh Folders. File teks dibaca per bagian sampai 4 MB, dan penampil menawarkan untuk membaca lebih banyak.
:::

## Rincian tidak bisa diubah
Questions: mengapa saya tidak bisa mengubah tanggal pengambilan; mengapa dikatakan rincian foto tidak bisa ditulis; mengapa Folders bilang hanya bisa mengubah catatan di foto JPEG dan PNG; apa arti tanggal pengambilan harus berbentuk; mengapa rincian lagu tidak bisa ditulis

Properti memungkinkan Anda mengubah tanggal file, apakah file hanya-baca atau bisa dijalankan, catatan dalam foto, dan tag lagu. Jika perubahan ditolak, kata-kata merah di bawah barisnya menyebutkan sebabnya, dengan **Lainnya** yang tenang di sebelahnya. Tidak ada yang berubah separuh: foto ditulis di samping yang lama lalu dipasang, jadi kegagalan meninggalkan yang lama tetap utuh.

![Bagian Rincian di Properti untuk foto bernama beach.jpg. Kotak Diambil berisi 2026-01-02 03:04 dan kata-kata merah di bawahnya menyatakan tanggal pengambilan harus berbentuk 2026-01-02 03:04:05, dengan tombol Selengkapnya bulat.](img/folders-details-refused.png "Yang akan Anda lihat: bagian Rincian di Properti setelah sebuah tanggal ditolak.")

- **Itu tidak bisa diubah, atau tanggal tidak bisa diatur.** File milik orang lain, atau disk atau folder tidak mengizinkannya. Sebabnya menyusul.
- **Tanggal pengambilan harus berbentuk 2026-01-02 03:04:05.** Tahun, bulan, dan hari, lalu jam, menit, dan detik.
- **Folders hanya bisa mengubah catatan di foto JPEG dan PNG.** Jenis lain bisa dibaca tetapi tidak ditulis.
- **Tidak ada ruang tersisa.** Disk tidak punya ruang untuk salinan baru foto.
- **Catatan terlalu panjang untuk dimuat di JPEG, tag terlalu besar, atau catatan tidak boleh berisi karakter nul.** Persingkat catatan.
- **Arah atas harus 1 sampai 8.**
- **Catatan foto rusak, dengan sebab seperti bagian yang melewati akhir.** Catatan di dalam foto tidak masuk akal, jadi Folders tidak akan menimpanya.
- **Ini tautan.** Ubah file yang dituju tautan itu.
- **Rincian lagu tidak bisa ditulis.** Sebabnya menyusul.

:::expert
Catatan foto (EXIF) ditulis baru di bagian foto yang khusus untuk itu. Catatan pembuat kamera tetap di tempatnya, karena banyak yang menghitung posisinya sendiri dari awal. Tag lagu ditulis di tempat bila masih muat, dan jika tidak, di file baru di samping yang lama, yang menggantikannya.
:::

## Folder tidak mau terbuka
Questions: mengapa folder saya tidak mau terbuka; apa arti Anda tidak diizinkan membuka folder ini; apa arti folder ini sudah tidak ada; apa arti tidak ada apa pun di alamat itu; mengapa panel mengatakan komputer lain tidak menjawab

Saat panel tidak bisa menampilkan folder, panel menampilkan sebabnya sebagai pengganti file, dengan **Coba lagi** dan **Lainnya** yang tenang.

![Panel Folders untuk folder bernama Private. Panel kosong kecuali kata-kata merah yang menyatakan Anda tidak diizinkan membuka folder ini, dengan tombol Coba lagi dan tombol Selengkapnya bulat.](img/folders-folder-not-open.png "Yang akan Anda lihat: folder yang tidak mau terbuka.")

- **Anda tidak diizinkan membuka folder ini.** Folder milik orang lain, atau pemiliknya menutupnya bagi Anda.
- **Folder ini sudah tidak ada.** Folder dipindahkan, diganti namanya, atau dihapus. Naik satu tingkat dan lihat lagi.
- **Folder ini tidak dapat dibaca.** Folders tidak diberi sebab yang lebih jelas. Drive yang dicabut, atau disk yang rusak, bisa menyebabkan ini.
- **Tidak ada apa pun di tempat itu.** Yang Anda ketik di kotak alamat bukan folder, file, atau tempat yang dikenal Folders. Periksa ejaannya.
- **Komputer lain tidak menjawab.** Tempat di jaringan, folder bersama, atau drive yang sudah tertidur diberi waktu singkat untuk menjawab. Jika tidak, panel berhenti menunggu, agar sisa jendela tetap cepat, dan menawarkan **Batal** dan **Coba lagi**.

:::expert
Sebuah tempat ditanyai di luar utas jendela sendiri, jadi tempat yang tidak pernah menjawab tidak bisa membekukan Folders. Paling banyak delapan pemeriksaan tempat berjalan bersamaan, jadi mencoba berulang kali tidak menumpuknya.
:::

## Warna dan emblem tidak ikut pindah
Questions: mengapa warna folder saya hilang setelah saya pindahkan; apa arti warna dan emblem tidak bisa ikut pindah; mengapa emblem hilang setelah ganti nama

Warna yang Anda beri pada folder, dan emblem yang Anda tambahkan ke file atau folder, disimpan oleh Folders di dua file kecil miliknya, `files-colours` dan `files-emblems`, di folder `trindle` pada pengaturan Anda. Keduanya terikat pada sebuah tempat, jadi saat Anda memindahkan atau mengganti nama sesuatu, Folders memindahkan warna dan emblemnya juga. Jika Folders tidak bisa menulis file itu, Folders mengatakan "Warna dan emblem tidak bisa ikut pindah."

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan Warna tidak dapat mengikuti apa yang dipindahkan, dengan tombol Selengkapnya bulat di kanan.](img/folders-colours-lost.png "Yang akan Anda lihat: bagian bawah jendela setelah warna tidak mengikuti pemindahan.")

Artinya: file atau folder berhasil dipindahkan. Warna dan emblemnya mungkin masih tampil sampai Anda menutup Folders, lalu hilang dari tempat baru. Tidak ada yang lain yang hilang.

Yang harus dilakukan: kosongkan ruang di disk, atau periksa bahwa folder pengaturan boleh Anda tulisi, seperti di [Pilihan yang tidak tersimpan](folders.html#choices-that-were-not-kept). Lalu beri warna atau emblem itu lagi.

:::expert
Tiap file ditulis sebagai file baru yang menggantikan yang lama, jadi penulisan yang gagal meninggalkan yang lama utuh. Pemindahan atau penggantian nama folder membawa warna dan emblem semua isinya juga, dan Urungkan membawanya kembali.
:::

## Seret dari atau ke program lain tidak selesai
Questions: mengapa tidak terjadi apa-apa saat saya menjatuhkan file ke Folders; apa arti tidak ada yang dibawa; mengapa dikatakan program lain tidak menerima semua yang diseret; mengapa dikatakan yang dimilikinya adalah salinan; mengapa file yang dijatuhkan dibiarkan di tempatnya

Program lain bisa menyerahkan file ke Folders dengan menyeret, dan Folders bisa menyerahkan file ke program lain. Kedua pihak tidak bisa melihat apa yang dilakukan pihak lain, jadi Folders memeriksa dan memberi tahu Anda bila ada yang tidak berjalan semestinya.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan program lain tidak mengambil semua yang diseret, jadi tidak ada yang dipindahkan di sini, dengan tombol Selengkapnya bulat di kanan.](img/folders-drag-short.png "Yang akan Anda lihat: bagian bawah jendela setelah seretan yang tidak lengkap.")

- **Tidak ada, jadi tidak ada yang dibawa.** Nama yang diberikan program lain bukan file yang ada, atau bukan path biasa di komputer ini.
- **Folder tidak bisa dimasukkan ke dalam dirinya sendiri.**
- **Tempat file berada tidak menjawab, jadi tidak ada yang dibawa.** Drive atau komputer yang menyimpannya tertidur atau pergi.
- **Yang terakhir dijatuhkan masih diperiksa.** Tunggu sebentar dan jatuhkan lagi.
- **Jawab dulu pertanyaan tentang yang dijatuhkan.** Folders bertanya sebelum mengambil apa pun yang disebut sendiri oleh program yang tersembunyi, atau di luar folder beranda dan drive Anda, karena program mana pun bisa menyebut file apa pun.
- **Tidak ada yang datang, yang dijatuhkan terlalu besar atau terlalu lambat atau terlalu banyak, atau bukan daftar file di komputer ini.** Jatuhkan lebih sedikit sekali waktu, atau pakai Salin dan Tempel.
- **Program lain tidak menerima semua yang diseret, jadi tidak ada yang dipindahkan di sini** (untuk pemindahan), **jadi mungkin tidak punya semuanya** (untuk penyalinan). File asli Anda masih di tempat semula. Periksa apa yang sampai.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan program lain mengambil yang diseret dengan cara yang tidak dapat menunjukkan bahwa ia membacanya semua, jadi tidak ada yang dipindahkan di sini, dengan tombol Selengkapnya bulat di kanan.](img/folders-drag-unshown.png "Yang akan Anda lihat: seretan yang diambil program lain dengan cara yang tidak dapat diperiksa.")

- **Program lain menerima yang diseret dengan cara yang tidak bisa menunjukkan bahwa semuanya terbaca, jadi tidak ada yang dipindahkan di sini: yang dimilikinya adalah salinan.** Sama, untuk program yang menerima salinan dan tidak bisa mengatakan salinan itu utuh. Hapus sendiri file asli setelah Anda memeriksanya.
- **Sesuatu berubah setelah diambil, jadi masih di tempat semula.** Diedit di antara pengambilan dan penjatuhan.

:::expert
Nama yang dijatuhkan program harus berupa path absolut biasa tanpa bagian titik, tanpa karakter kontrol, dan dengan panjang terbatas. Pemindahan ke program lain tidak dilakukan sebagai pemindahan: aslinya hanya dihapus setelah salinannya diketahui utuh, yang pada beberapa program tidak bisa diketahui.
:::

## Sesuatu tidak bisa dibuat di sini
Questions: mengapa Folders tidak bisa membuat folder baru; mengapa tautan tidak bisa dibuat; mengapa gambar ini tidak bisa jadi gambar latar; mengapa font tidak bisa dipasang

Folders membuat folder, dokumen, tautan, dan font yang dipasang, dan mengatur gambar latar. Saat tidak bisa, kata-kata merah menyebutkan apa itu dan mengapa, dengan **Lainnya** yang tenang.

![Jendela Folders dengan daftar berkasnya. Di bagian bawah, kata-kata merah menyatakan Folder baru tidak dapat dibuat karena izin ditolak, dengan tombol Selengkapnya bulat di kanan.](img/folders-make-failed.png "Yang akan Anda lihat: bagian bawah jendela setelah folder baru tidak dapat dibuat.")

- **Folder atau dokumen baru tidak bisa dibuat.** Folder hanya-baca, Anda tidak boleh menulis di dalamnya, atau disk penuh. Sebabnya menyusul. Buat di folder milik Anda sendiri.
- **Tautan tidak bisa dibuat.** Kata-kata menyebutkan berapa banyak dan menyebut namanya. Tautan memerlukan nama yang bebas di folder itu dan folder yang boleh Anda tulisi.
- **Gambar tidak bisa jadi gambar latar.** Gambar latar bisa sampai 4K (3840 kali 2160). Gambar diam bisa 20 MB dan gambar bergerak 200 MB. Kata-kata menyebutkan batas mana yang dilewati. Lihat juga [Gambar latar dilewati](troubleshooting.html#a-wallpaper-is-left-out).
- **Font tidak bisa dipasang.** Font disalin ke folder font di folder data Anda sendiri. Jika folder itu tidak bisa dibuat atau ditulisi, font tidak dipasang.

## Perbandingan atau pencarian berhenti
Questions: mengapa perbandingan berhenti; mengapa dua file tidak bisa dibandingkan; mengapa pencarian salinan berhenti; apa arti 1 file tidak bisa dibaca dan dikeluarkan

Bandingkan keduanya, perbandingan folder, dan Duplikat membaca banyak file. Jika salah satunya berhenti atau menemui file yang tidak bisa dibacanya, kata-kata merah mengatakannya dengan **Lainnya** yang tenang.

![Jendela Bandingkan untuk notes.txt dan readme.txt. Kata-kata merah menyatakan Keduanya tidak dapat dibandingkan, dengan alasannya dan tombol Selengkapnya bulat.](img/folders-compare-stopped.png "Yang akan Anda lihat: jendela Bandingkan setelah perbandingan berhenti.")

- **Keduanya tidak bisa dibandingkan, perbandingan berhenti, atau pencarian berhenti, dengan sebab.** File berubah atau hilang saat dibaca, drive hilang, atau Anda tidak boleh membacanya. Jalankan lagi.
- **N file tidak bisa dibaca dan dikeluarkan.** Duplikat membaca setiap file untuk memastikan dua file sama. File yang tidak boleh dibacanya tidak masuk dalam jawaban, jadi daftar mungkin kehilangan beberapa kelompok.

Tidak ada yang diubah oleh semua ini. Semuanya hanya membaca.
