Teks membuka, mengedit, dan menyimpan teks biasa. Ini adalah program bawaan untuk teks biasa, Markdown, log, dan file kode sumber.

## Dasar-dasarnya

- **Beberapa file sekaligus.** File terbuka sebagai deretan tab ramping, masing-masing dengan tombol tutup kecilnya sendiri. Teks mendapat ruang terbesar.
- **Pekerjaan tidak pernah hilang.** Teks menyimpan selagi Anda bekerja. Menutup sesuatu yang belum disimpan ke file akan bertanya dulu.
- **Menyimpan tidak pernah menghilangkan kata-kata lama.** Teks menulis kata-kata baru ke file baru di samping dokumen. Lalu file itu menggantikan yang lama dalam satu langkah. Namanya selalu mengarah ke seluruh file lama atau seluruh file baru, bahkan jika listrik mati di tengah jalan. Jika penyimpanan terputus, Teks memperbaikinya saat dimulai berikutnya.
- **Pengodean lain.** Pengodean adalah cara huruf disimpan dalam file. Teks membaca dan menulis file dalam pengodean aslinya, selain UTF-8.
- **File terbaru.** Teks menyimpan daftarnya. Satu pengaturan memilih apa yang terjadi saat dibuka. Membuka kembali file dari terakhir kali, atau mulai dengan satu dokumen kosong.

## Mengedit

Teks punya nomor baris, pembungkus baris yang bisa dinyalakan atau dimatikan, cari dan ganti, penghitung kata dan huruf, dan ke baris.

Urungkan dan Ulangi adalah tombol bulat di bilah atas setelah tombol menyimpan. Masing-masing berwarna abu-abu saat tidak ada yang bisa diurungkan atau diulangi.

Untuk mencari sebuah kata:

1. Tekan Ctrl+H, atau tombol cari dan ganti di bilah atas.
2. Ketik kata itu di bilah yang terbuka.
3. Teks menampilkan kata yang ditemukan di halaman. Teks menghitungnya, misalnya 1 dari 2, dan panah berpindah di antaranya.

![Teks dengan daftar belanja pendek terbuka dan kata susu ditemukan di dua tempat.](img/text-found.png "Yang akan Anda lihat: bilah cari dengan kata susu, dan kata yang ditemukan terlihat di dalam daftar.")

Pemeriksaan ejaan memakai kamus yang sudah ada di komputer. Kecuali Pengaturan menyebut satu, Teks memakai bahasa Inggris Britania jika ada. Berikutnya bahasa komputer itu sendiri, lalu bahasa Inggris Amerika.

Anda bisa mengubah font dan ukurannya. Tampilannya mengikuti tampilan Trindle sendiri, gelap atau terang.

## Markdown

Markdown adalah cara menulis teks biasa dengan tanda sederhana untuk judul dan daftar. Dalam mode Markdown, satu panel berganti antara teks mentah dan tampilan jadi. Keduanya tidak ditampilkan berdampingan. Anda bisa menyimpan tampilan jadi sebagai PDF atau HTML.

## Menutup

- Tombol tutup di bilah judul dan Ctrl+Q menutup Teks. Setiap dokumen yang pekerjaannya belum disimpan ditanyakan satu per satu.
- Ctrl+W, atau tombol tutup milik tab, menutup satu dokumen itu dan tidak pernah menutup Teks itu sendiri. Menutup yang terakhir meninggalkan satu dokumen kosong sebagai gantinya.
