# Security policy

Trindle translations is a small project run by one maintainer, not a company with a security team. This page says what to expect.

## Supported versions

Only the latest version is supported. There is no older branch and no backporting.

| Version | Supported |
|---|---|
| 0.1.0 | yes |

## Reporting a problem

Please do not put the details of a security problem in a public post. Use GitHub's private vulnerability reporting on this repository (the Security tab, then Report a vulnerability). If that is not possible, email translations@trindle.org.

Useful things to include: what you found, which file or tool, how to repeat it, and the version.

## What to expect

You will get a reply. A fix goes into the next version, and the changelog says so. This is a volunteer-sized project, so there is no fixed repair time and no reward scheme.

## What counts

- A tool that can write outside the folders it is given, or run something it should not.
- A translated line that could mislead a person into a harmful choice, for example a wrong word in a permission prompt. Send it to the Buildmorphic community if it is only a poor translation, and here if it looks deliberate.
